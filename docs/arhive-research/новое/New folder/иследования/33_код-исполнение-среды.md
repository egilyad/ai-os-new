# Отчёт сабагента: Исполнение кода, среды, очереди

## 1. Sandbox — два слоя

**Слой A — реальный, worker (SandboxService).** sandbox-service.ts на каждый execute() создаёт отдельный Web Worker (sandbox.worker.ts) → AST-интерпретатор sandbox-interpreter.ts. Гейт: codeExecutionEnabled = DEV || VITE_SANDBOX_ENABLED==='true' (в проде выключен). Хост-контроль: allowedTools (whitelist) + MAX_TOOL_EXECUTIONS=10. fetchUrl: только HTTPS + запрет private IP + таймаут + fallback прокси.
**Слой B — G5, заглушка (CodeSandboxService).** code-sandbox-service.ts — «static gap closure»: политика (allowedLanguages/banned/maxChars/defaultTimeoutMs), таймаут, артефакты. **Делегат по умолчанию — заглушка BLOCKED-RUNTIME** («real E2B not wired», :138). phase58 регистрирует codeSandboxService, но нигде не резолвится, не подключён к worker; setExecutor() не вызывается. CodeExecService (rivals5) только валидирует и ждёт внешнего делегата (queued).
Что реально исполняется: только sandbox-interpreter.ts через sandbox.worker.ts. Остальное — честные «тикеты»/артефакты.
Риски: побег ограничен глобалами воркера (нет DOM/window/localStorage); разделяемые живые встроенные объекты допускают замусоривание прототипов воркера (worker свежий на каждый запуск — межзапускового заражения нет).
Тесты: code-sandbox-service.test.ts, sandbox-interpreter.test.ts. **Нет тестов** на SandboxService.execute, codeexec-service.

## 2. sandbox-interpreter (1906 строк)

- meriyah-AST-интерпретатор (не eval/new Function), работает под строгим CSP.
- Подмножество JS: выражения/операторы, функции/стрелки/async-await/try-catch/циклы/switch/labeled break/деструктуризация/spread/regex/bigint. Запрещено: классы, генераторы, with, import().
- Шаг-лимит MAX_STEPS_DEFAULT=2_000_000; глубина MAX_DEPTH_DEFAULT=2000.
- Whitelist-глобалы (SAFE_BUILTINS): Math, Date, JSON, crypto, URL, типизированные массивы, TextEncoder/Decoder, Number/String/Boolean/Array/Object/Promise/Symbol, ошибки, RegExp, Map/Set/WeakMap/WeakSet, ArrayBuffer, DataView, BigInt, parseInt/parseFloat/isNaN/isFinite/encodeURIComponent/... , os, data, console, self/globalThis (проксированные), undefined/Infinity/NaN.
- Запрещённые идентификаторы (~40): importScripts, XMLHttpRequest, fetch, WebSocket, indexedDB, eval, Function, arguments, Proxy, Reflect, Atomics, SharedArrayBuffer, WeakRef, FinalizationRegistry, caches, Cache, CacheStorage, BroadcastChannel, MessageChannel/Port, EventSource, Event, CustomEvent, URLSearchParams, Blob, File, FileReader, FormData, Headers, Request, Response, globalThis, self, window, parent, top, setTimeout/setInterval/clear*, queueMicrotask, requestAnimationFrame, cancelAnimationFrame, structuredClone, performance.
- Запрещённые члены: constructor, **proto**, prototype, getPrototypeOf, setPrototypeOf, defineProperty(s), **defineGetter**/Setter__, **lookupGetter**/Setter__, caches, registration, serviceWorker, onmessage/onerror/onclose. Вычисляемый доступ блокируется (obj["constructor"], obj[k], obj[expr]).
- Защита: среда на Env (Map-биндинги); глобальный объект — Proxy(Object.create(null)) с set→false/deleteProperty→false/isExtensible→false/ownKeys ограничен; второй рантайм-уровень assertMemberAccess.
- Пробелы/evasion: члены SAFE_BUILTINS — живые ссылки на реальные объекты воркера (прототип-поллюция внутри воркера; ограничена одним запуском). Полного hardening нет.

## 3. Python-runner

**Реального запуска Python нет.** python-runner-service.ts: run() — симуляция (регулярка print\s*\(...\) выдёргивает аргументы; остальное — no output). Нет pyodide/WASM/серверного рантайма. validateFile() — баланс скобок + regex blockedModules (subprocess/shutil/ctypes/socket/http/asyncio); allowedModules (python-runtime-types.ts DEFAULT_SANDBOX_CONFIG) не используются при симуляции. Контракт есть; заглушка. Тесты покрывают только симуляцию.

## 4. CodeRunner (UI)

components/ChatPanel/CodeRunner.tsx — отдельная iframe-песочница, не связана с kernel-воркером/CodeSandboxService. Выполняет html/css/js/ts в iframe sandbox="allow-scripts" (без allow-same-origin → opaque origin), CSP default-src 'none'; script-src 'unsafe-inline'; connect-src 'none' (нет сети). JS через escapeForScriptContent; HTML через DOMPurify allowlist. Таймаут 10с, перехват console, кап 200 логов, обрезка 5000. Python НЕ поддерживается («not yet supported»).

## 5. execution-queue / runqueue

- ExecutionQueue (services/execution-queue.ts): 5 приоритетов critical>high>normal>low>background; FIFO; maxConcurrency 3; watchdog-таймаут 120с; MAX_QUEUE_TASKS=10_000 (переполнение — дроп); при ошибке/зависании — события + IDeadLetterQueue. **Retry не реализован** (retryCount всегда 0). Тесты есть.
- RunQueueService (rivals/runqueue-service.ts): очередь crew/graph/eval, персист в RivalRepository, drain(concurrency) cap 1–4. Без retry/DLQ.

## 6. execution-governor

ExecutionGovernorService: жизненный цикл pending/running/completed/failed/cancelled/timed-out; AbortController; дерево родитель/потомок, cancelTree, drain, getDescendants. **НЕ ограничивает параллельность** (нет maxConcurrency) — только lifecycle/учёт/таймауты.

## 7. Выводы

1. BLOCKED-RUNTIME: реальное E2B не подключено; CodeSandboxService заглушка; Python симуляция; исполняется только JS-интерпретатор (только DEV/флаг).
2. Evasion: живой разделяемые объекты → прототип-поллюция внутри воркера; constructor-побег закрыт; хост-интерфейс только os.executeTool (allowedTools + лимит 10).
3. Нет тестов: sandbox-service (worker-оркестрация, rate-limit, allowedTools), codeexec-service, интеграция, retry DLQ.
4. Нет ресурсных лимитов ОС (память/CPU) — только шаг/глубина и wall-clock таймаут.
5. Риск включения прода: гейт VITE_SANDBOX_ENABLED расширяет threat model.
6. CodeRunner (UI) — предпросмотр, не инфраструктура агентов.
