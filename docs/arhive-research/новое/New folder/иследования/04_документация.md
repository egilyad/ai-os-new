## 3. Что такое SuperAgents OS

Браузерная ОС для оркестрации распределённого интеллекта. Local-first (IndexedDB/Dexie), сервера нет. Слои: UI (React-панели) → Kernel (SystemKernel, шина, DI, ~50 фаз регистрации) → Infrastructure (LLM-адаптеры, воркеры, Dexie). Шина событий lossy/in-memory — UI обязан гидрироваться из Dexie. Стек: React 19, Vite 8, TS 6, Dexie, Orama (BM25, Web Worker), Transformers.js, Kernel Hardening (deepFreeze/validateState/clamp).
