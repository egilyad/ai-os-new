# Отчёт сабагента: Концепции, философия, позиционирование

## 1. Философия / миссия

- «Не чат-бот, а браузерная когнитивная ОС для оркестрации распределённого интеллекта» (README, what-is, SYSTEM_PASSPORT).
- Из PASSPORT: observable cognitive runtime — «наблюдаемый когнитивный рантайм»; **Decision (решение) — первоклассный объект рантайма**; каждое рассуждение интерпретируемо/воспроизводимо/программируемо. Миссия: сделать ИИ «не чёрным ящиком, а прозрачной, управляемой, самоулучшающейся инфраструктурой».
- Отличие от чат-бота: не один диалог, а экосистема (дебаты, команды, инструменты, память, диагностика); типизированная шина событий; маршрутизация (UCB1/broadcast/race).
- Отличие от фреймворков (LangChain/AutoGen/CrewAI/Dify): собственный UI из 268 панелей (ОС, а не SDK); Линзы/Кристаллы/Синтез/33+75 дебатов; акцент на наблюдаемости (Decision-центричная модель, когнитивные трейсы, time machine); local-first.

## 2. Уникальные подсистемы (map-02, 6 killer-фич)

1. Когнитивные линзы (LensesPanel) — структурные перспективы.
2. Хранилище кристаллов ⭐ (CrystalVaultPanel) — lifecycle semi→crystal→superseded→refuted; «долговременная память выводов».
3. Движок синтеза ⭐ (SynthesisPanel) — мультиперспективный консенсус, зоны consensus/dissent/uncertainty. Топ-3 уникальных.
4. Конструктор когнитивных пайплайнов ⭐ (BuilderPanel) — React Flow, deploy. «IDE для агентов».
5. Time Machine ⭐ (TimeMachinePanel) — снапшоты + restore + diff по 5 скоупам.
6. Дебаты + техники ⭐ (DebateArena, 62 TechniquePanels) — 33 стратегии + 75 техник. Главная отличительная черта.
   Вывод map-02: ~268 панелей = 6 killer-фич + стандартная обвязка; Minimum viable ≈ 40 панелей дают 90% ценности. Риск: «6 killer-фич теряются среди 268 панелей».

## 3. «Идея» / «рабочая станция» (idea-path, 8 этапов)

Проект позиционирует себя как «второй мозг»: «система не делает за тебя, а усиливает мышление». 8 этапов: Захват → Прояснение/дебаты → Исследование (RAG) → Глубокий анализ (~60 техник) → Синтез → Проверка качества (ELO/A/B) → Организация/исполнение → Моделирование (симуляция/time machine/what-if). Каталог 50 сценариев.

## 4. Обещанные сценарии

Провайдеры (ключи, стриминг, цепочка декораторов); Чат (single/broadcast/race, UCB1); Агенты (персоны, топологии, Elo, маркетплейс); Память (BM25+семантика, 7 типов); Конструктор; Дебаты (33 стратегии, 75 техник, replay, турниры, HITL); След исполнения; Диагностика.

## 5. Архитектурные принципы (манифест)

Core Paradigm: **Observable Distributed Cognition**. Decision-centric; Event-driven (198 схем, lossy/in-memory); Multi-agent/debate-driven (5 когнитивных слоёв: Execution→Coordination→Reasoning→Observability→Interpretation); Local-first; Observable/programmable (трейсы, DSM, конструктор, Advisor); Технические (reducer, транзакции, lifecycle, Web Worker sandboxing, Blackboard, MCP).

## 6. Локальность / приватность / один пользователь

- README: «API-ключи в открытом виде… однопользовательский, одномашинный».
- Парадокс: заявляется single-user local-first, но есть enterprise/коллаборативные подсистемы (Флот, Governance/RBAC, Федеративная память, компании, gateway) — map-02 называет их stub.

### Принципы-компасы (для развития)

1. Не добавлять случайные фичи — закрывать интеграционные пробелы (топ-3: Builder×killer-сервисы, import/round-trip, provenance).
2. Сделать конструктор настоящей IDE (exposed synthesis/crystal/lens/memory/time-machine как узлы) — главный архитектурный unlock.
3. Восстановить local-first до конца (import для всех export; единый круглый путь бэкапа).
4. Выстроить когнитивную цепочку provenance (debate→memory→crystal→synthesis двунаправленно).
5. Фокусировка на 6 killer-фичах (top-level раздел Cognitive Engine, onboarding, сократить до ~150 панелей).
6. Честность маркировки (бейджи Experimental/Stub/Deprecated; скрыть декоративное за feature-flag).
7. Доверие через тесты (закрыть пробелы ядра, починить пустой timeline/alts[0]/рассинхрон памяти).

### UVP

> SuperAgents OS — единственная браузерная «когнитивная ОС», которая делает распределённое ИИ-рассуждение наблюдаемым и программируемым: через таксономию дебатов (33+75), долговременную память выводов (кристаллы), мультиперспективный синтез и конструктор когнитивных конвейеров — всё локально, в браузере, с данными на машине. Это не очередной мультипровайдерный чат, а «второй мозг».
> **Главный разрыв:** концепция и ядро зрелые, но уникальные подсистемы плохо интегрированы и теряются среди 268 панелей — стратегическое направление = интеграция и фокусировка, а не новые фичи.
