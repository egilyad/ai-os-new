# Отчёт сабагента: Наблюдаемость, метрики, советник, ELO, eval

## 1. timeline/

- TimelineMap — декларативная карта событий → {category, title, severity, entity}; TIMELINE_MAP покрывает **60 событий** из запланированных 260 (переносим по 10).
- ExecutionVizService (G3): init() подписывается на все ключи TIMELINE_MAP через events.onSafe; извлекает runId (каскад runId ?? sessionId ?? crewId ?? traceId ?? graphId ?? id) и строит span {id,type,category,timestamp,title,severity,source:'execution-viz',metadata,traceId,runId,entityId}. Кэш runSpans: Map<runId, spans> (до 500 спанов, splice). Лимиты: 500 спанов/runId, поиск limit 200/500. getOverlay: direct spans + timeline-события (дедуп по id, сортировка по timestamp) + stats; фолбэк TraceService.getTrace. listOverlays(graphId). subscribe(). Тест есть.

## 2. ops/

- AuditService: append-only hash-chain (fnv1a(prevHash|seq|actor|action|target|detail|ts), 32-bit hex, genesis '00000000'); append() — lastAuditSeq()+1, обрезка detail до 2000, emit OPS_AUDIT; verify() реплеит, лимит 100 000 строк (truncated), brokenAt.
- FleetMonitorService: read-only наблюдатель; подписки CREW__/COUNCIL__/GRAPH_*; MissionWatch; snapshot() {missions, counts}.
- HierarchyService: дерево CEO→подчинённые + бюджеты; recordSpend кидает при overspend; аудит (node.created/budget.set/spend.recorded/denied/node.removed).
- ToolGovernanceService: реестр MCP + per-agent grants; check(agentId,tool) — default-deny, explicit denies побеждают, паттерны (_, prefix:_, exact).
- SandboxBrokerService: E2B-тикеты (kind/agentId/purpose/status/ttlMs 10мин); lifecycle requested→approved/denied→running→done/expired; аудит + OPS_SANDBOX. Реального песочника нет.
- SkillMarketService: манифесты {name,version,description,permissions,entry,author,installed}; lifecycle publish→install/uninstall; статический кэш для синхронного exportManifest; дублирует SkillService («future bridge»).
- MobileAccessService: 6-digit pairing; quickApprove/quickReject → IGraphService; quickVote → ICouncilService; аудит. **Опечатка:** `councils`.
- BuilderBridge: executeBuilderManifest — компилирует WorkflowManifest в State Graph (KIND_MAP: agent→task, debate→council, synthesis→reflection, gate→gate).

## 3. advisor/ (все — эвристики, кроме InsightEngine с LLM-опцией)

- DiagnosticsEngine: классификатор ошибок провайдеров по строкам; providerErrorHistory; recentCount за 5 мин; analyzeKey; getHealthScore (critical −25/warning −10/info −3, floor 0).
- PressureEngine: 4 сигнала (latency/throughput/errorRate/saturation); формула: status(25%)+(1-reliability)*100(15%)+quotaPct(20%)+budgetPct(10%)+errorRate*100(10%)+saturation*100(10%)+latency*100(10%), clamp 100; уровни ≥80 critical/≥60 high/≥35 medium/≥10 low; startAutoRefresh(10s).
- OptimizationEngine: до 20 OptimizationSuggestion, до 100 SREAlert; propose() дедуп; executeFix() через verify-gate (runGatedChange: snapshot→apply→verify→rollback); checkBudgetHealth() при 90%/75%.
- InsightEngine: единственный с LLM-путём; analyzeTraces() эвристика; generateLLMAnalysis() — router, пропуск мёртвых, LLM «analyze metrics + topology → JSON»; generateAnswer() SRE-агент; **costPerRequest/providerReliability никем не заполняются (0)**.
- WhatIfEngine: analyzeAddKey/analyzeSwitchProvider/analyzeBudgetChange/getRuntimeScenarios; **getPromptCachingAdvice() — заглушка, всегда null**.

## 4. runtime-intelligence/

- DiagnosticService: обёртка над CognitiveIntelligenceService; getSystemDiagnostic (critical/high/healthy; score=1-critical*0.3-high*0.1); runDiagnostic('system') каждые 30с (история ≤200); getSessionDiagnostic (кэш ≤50); **getProviderDiagnostic — пустышка «Provider never diagnosed»**.
- PressureMapService: подписки DEBATE_BUDGET_*/KEY_HEALTH_CHECK_COMPLETED/KEY_LATENCY_BURST/сессии; providerPressures/sessionPressures/trendHistory (≤500)/alerts (200, cooldown 60с); levelToScore: critical .9/high .7/normal .45/low .15; emit PRESSURE_MAP_UPDATED/PRESSURE_ALERT_RAISED.
- WhatIfService: simulateTopologyChange/ParticipantChange (делегирование), simulateBudgetChange (эвристика ratio), simulateProviderChange, simulateStrategyChange (табличные веса), **simulatePolicyDryRun — использует реальные данные, но при отсутствии падает на захардкоженные мок-ноды (node_1..5)**. История ≤200.

## 5. cognitive-intelligence/

- CognitiveIntelligenceService: оркестратор 4 движков; подписки дебата; sessionSummaries Map (≤100); refresh() каждые 10с.
- CognitiveMetricsEngine: debateQuality = (1-avgContradictionDensity)*0.4 + consensusConfidence*0.3 + reasoningCoherence*0.3; cohesion; reasoningCollapseDetected (contrad>0.6 && conf<0.3); hallucinationZones.
- CognitivePressureEngine: rawScore = complexity*0.35 + contention*0.25 + memory*0.25 + activeChains/10*0.15; пороги ≥0.8/≥0.6/≥0.3.
- CognitiveDiagnosticsEngine: issues: contradiction_spike (delta>0.3), reasoning_collapse, confidence_drop (delta>0.25), budget_pressure (tokens>80k/95k), agent_failure; глобально ≤200.
- CognitiveWhatIfEngine: simulateTopologyChange (TOPOLOGY_COMPLEXITY), simulateParticipantChange (убывающая отдача).

## 6. contracts/observability.ts + custom-metrics.ts

- observability.ts: TimeSeriesPoint, AggregatedMetrics, ProviderMetricSummary, MetricsThreshold, MetricAlert, TraceFilter, TraceStep, TraceDataQuality, ExecutionTrace, TraceExport, TimelineEvent, TimelineEventType (30 значений), TimelineCategory, TimelineFilter, ITimelineContract.
- custom-metrics.ts: ICustomMetricsService (list/get/create/update/delete, computeValue, getHistory, dashboards); CustomMetric {aggregation avg/sum/max/min/count/p50/p95/p99, source provider/debate/memory/system, field, filter, unit, color}; MetricValue; MetricDashboard. **Статус: только контракт — реализация не найдена.**

## 7. utils/percentile.ts

Линейная интерполяция: idx=(len-1)_p, lo=floor, hi=ceil; lo===hi → sorted[lo], иначе sorted[lo]+(sorted[hi]-sorted[lo])_(idx-lo). Пустой → 0.

## 8. elo/

EloRatingService: initial 1200, K=32, minK=16 после 100 игр, floor 100, ceiling 3000; expectedScore=1/(1+10^((B-A)/400)); updateRatings(winnerId,loserId,result) — result ('win'/'loss'/'draw') c перспективы winner; wins/losses/draws/peakRating/ratingHistory (1000→500); localStorage elo-ratings:profiles; emit ELO_RATING_UPDATED; MAX_PROFILES=500. **grep: никаких фактических вызовов updateRatings — ELO не подключён (мёртвый).**

## 9. eval/

- LlmJudgeService: **заглушка** (G8 stub, PROVIDER-PENDING); если ILLMClientService внедрён → реальный LLM-judge (prompt «score 0..1 vs reference», JSON, fallback stub); иначе stubScore = token_f1 (passed≥0.5); emit EVAL_JUDGE_DONE.
- ScorerRegistryService: builtins contains/exact/token_f1; score(case, output, scorer?) default c.metric ?? 'contains', clamp [0,1]; register() перезаписывает, EVAL_SCORER_REGISTERED.
- EvalDatasetService (services/eval-dataset-service.ts, вне eval/): localStorage eval_datasets_v2, версионирование, глобальный мьютекс withLock; runEval — реальный прогон (adapter, latencyMs, score=0, скор = computeSimilarity (Jaccard) — третья реализация сравнения); summary total/passed/failed/avgLatency/avgScore/totalCost; ≤50 прогонов.
- Тесты: только scorer-registry-service.test.ts. eval-dataset-service и elo-service без тестов.
