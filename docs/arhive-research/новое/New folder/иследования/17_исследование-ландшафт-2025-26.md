## (б) Ключевые тренды

1. Протоколы — стандарт: MCP + A2A v1.0 (интероперабельность между фреймворками).
2. Eval и observability — встроенные (OpenAI tracing, LangSmith Engine, ADK Cloud Trace, OpenTelemetry GenAI).
3. Безопасность агентов — OWASP LLM Top10 2025 + Agentic Security.
4. Sandbox / «компьютер» — первоклассная абстракция (OpenAI Sandbox, Claude Agent SDK, Letta computers).
5. Managed-рантаймы / «агенты как сервис» (LangSmith Deployment, Claude Managed Agents, ADK Agent Runtime, CrewAI Platform, Dify Cloud).
6. Визуальные конструкторы (ADK Visual Builder, LangSmith Fleet, Dify, n8n).
7. Код как действие — генерация/исполнение кода — центральный механизм.

## (в) Рекомендации для SuperAgents OS

1. Поддержать MCP (есть) + A2A v1.0 (клиент и/или сервер) — конкурентное преимущество.
2. Оркестрация: концепция AG2 Network (Hub + каналы + write-ahead log/audit trail) + графовый control-flow (LangGraph).
3. Память/state: у Letta — MemFS, shared memory, subagents с изоляцией контекста, compaction; сохранять состояние между вкладками/запусками.
4. Безопасность браузера: OWASP LLM Top10; permission-модель + sandbox (OpenAI Sandbox / Letta permissions / ADK confirmations).
5. Obs-абстракция «компьютера»: изолированные возобновляемые сессии (iframe/вкладка/профиль).
6. Observability+eval с первого дня: трассировка OTel-совместимая + eval-наборы.
7. Sandbox для агентов-кодеров: codegen + lint + визуальный фидбек.
8. Multi-provider: не привязываться к одной модели.
9. Визуальный конструктор оркестраций.
10. Позиционирование: «мультиагентный OS для браузера» — ниша на стыке провайдеров/состояния/безопасности.
