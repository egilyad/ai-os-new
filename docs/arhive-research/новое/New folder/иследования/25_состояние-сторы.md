## 4. RouterProjection

Чистая свёртка event-sourcing: reduce(event) фильтрует 'system:decision', требует requestId, строит ProjectedDecision; getState/getSnapshot (по timestamp desc)/cloneSnapshot (structuredClone)/getByRequestId/reset. router-shadow-diff.ts: compareRouterDecisions(live, projected) → missingInProjection/missingInLive/mismatches/severity/driftScore.

## 5. Дублирование / гидрация / пробелы

- 3 слоя одного и того же: сервис (канонический) + стор (проекция) + Dexie (персист). Пример: ключи в groupManager/keyService + Dexie apiKeys + useKeyStore (liveQuery И refresh).
- Дублирование в сторах: activeDebateStore.session зеркалит sessions[id].session; graph/trust/project делают полный refresh на каждое событие.
- Гидрация: localStorage persist (uiPreferences), Dexie liveQuery (chat/keyStore), сервисные вызовы (invocation/director/graph/trust/project).
- Пробелы: provider-state.stateHistory никогда не заполняется; agent-profiles легаси-дубликаты; разблокировка ключей живёт только на уровне флагов keyStateStore без интеграции со снапштотами; useKeyStore двойной путь; сторы графа/траста/проектов неинкрементальны.
