# Отчёт сабагента: Эмбеддинги, RAG, эвалы, трассировка

Замечания: каталог services/ml/ отсутствует; eval-dataset-service лежит в services/eval-dataset-service.ts; локальных Transformers.js нет — все локальные эмбеддинги хэш-основаны.

## 1. embeddings/

- EmbeddingClient (llm/embeddings/embedding-client.ts): POST {baseUrl}/embeddings; EMBEDDING_TIMEOUT_MS=30_000; L2-нормализация всегда; сортировка по index; проверка числа векторов; fetchImpl инжектится.
- ProviderEmbeddingService (memory/provider-embedding-service.ts): IEmbeddingPort; opt-in через CONFIG.services.memory.providerEmbeddings.enabled; embed() бросает если выключен/нет ключа; isAvailable(); EMBEDDING_BASE_URLS: openai/openrouter/nvidia/together/deepinfra/siliconflow/gemini/ollama/lmstudio.
- Локальные: DefaultEmbeddingService (parity/) — хэш FNV-1a, 3-пробинг в 384-мерный вектор, L2, дефолт для KnowledgeService и hybrid; getFNVEmbedding (utils/embedding.ts) — 128-мерный + cosine для memory-mesh; DebateEmbeddingPipeline (debate-runtime/) — чанкинг (max 512), cosine.
- Регистрация: phase75 (embeddingService, opt-in), phase32 (KnowledgeService DefaultEmbeddingService), phase81 (wiki-brain).

## 2. rag/

- Bm25Service: in-memory BM25, k1=1.2, b=0.75; токенизация (lowercase, split, длина>2); build(chunks); search(query,limit) — idf Окапи; строится заново на retrieveHybrid.
- HybridRetrievalService (G1, аддитивен): retrieveHybrid(query, opts?) — limit=5, bm25Weight=0.5, vectorWeight=0.5, useReranker=true, candidateMultiplier=4; кандидаты limit*4; BM25 + вектор (кэш, cosine); двойной catch (BM25→vector-only, вектор→BM25-only); RRF-fuse k=60 + примесь 0.05 нормированных сырых скоров; fallback [] → RagService откатывается на KnowledgeService.retrieve; эвент knowledge:hybrid:retrieved.
- RerankerService: StubRerankerService (детерминированная эвристика: hit/q.size × length-prior; rerankScore=0.7*fusedScore+0.3*heuristic); ProviderRerankerService — BLOCKED-RUNTIME (кросс-энкодер).

## 3. parity/KnowledgeService

- addSource({kind: url|text, title, uri?, content?}): URL-ingest best-effort (fetch 12с, вырезает script/style, slice(0,60000)); чанкинг ≤600 симв, cap 200 чанков; ParityRepository.putSource + knowledge:added.
- retrieve(query, limit=5): токен-оверлап score()=hit/q.size; если embedder — бленд 0.6*vector+0.4*token, кэш векторов; цитирование {sourceId, title, chunk}; RagService.answer() цитаты = уникальные title; synthesize просит LLM «Cite [n]».

## 4. parity/DefaultEmbeddingService

Хэш-based оффлайн: FNV-1a на слово, 3-пробинг в 384-мерный, L2. Только лексический сигнал.

## 5. eval/

- EvalDatasetService (services/eval-dataset-service.ts): localStorage eval_datasets_v2, withLock; CRUD; runEval — реальный прогон (adapter, latencyMs, tokens, cost=0, скор=computeSimilarity Jaccard, passed=score>=0.7); summary; ≤50 runs.
- LlmJudgeService (G8 stub): если ILLMClientService → реальный LLM-судья (prompt «Score 0..1 vs reference, JSON {score,passed,reasoning}», fallback stub); иначе stubScore=token_f1; via:'stub'/'llm'; EVENTAL_JUDGE_DONE.
- ScorerRegistryService: builtins contains/exact/token_f1; register; score(case,output,scorer?) default c.metric ?? 'contains', clamp [0,1].
- EvalService (frontier, Wave 12): createBenchmark; runBenchmark (через IFrontierExecutor, echo-fallback, scoreCase contains|exact|token_f1); compare (A/B, delta, EVAL_COMPARED); redTeam (регэксп маркеров отказа → blocked/unclear/bypassed); capabilityMatrix (статическая, Phase A-D done).

## 6. contracts/

- eval-dataset.ts: EvalPrompt, EvalRunResult, EvalRun {results, summary{total,passed,failed,avgLatency,avgScore,totalCost}}, EvalDataset, IEvalDatasetService.
- eval-scorer.ts: ScorerResult {score 0..1, passed}, ScorerFn, IScorerRegistryService, ILlmJudgeService.
- hybrid-retrieval.ts: HybridHit, HybridOptions, IBM25Port, IRerankerPort, IHybridRetrievalService.
- parity.ts: IEmbeddingPort {embed, describe?}, IKnowledgeService, ITrainingService, IToolRunnerService.

## 7. Реальное vs stub; для SPEC_04
