## 2. Сервер / sidecar / CORS-proxy

### sync-server.mjs (3001, loopback)

- HTTP + WebSocketServer (ws). Авторизация: единый Bearer `SYNC_SECRET` (или SYNC_SECRET_FILE, fail-fast). HTTP Authorization: Bearer; WS через verifyWsUpgrade (Sec-WebSocket-Protocol: sync-token,<token> или Bearer). timingSafeEqual, origin-проверка (SYNC_ORIGINS), HTTP rate-limit 30 req/60s/IP, WS 10 conn/60s/IP, maxPayload 1MB, XFF не доверяется (SYNC_TRUST_PROXY), тело ≤50MB.
- Store `company-store.mjs`: companies/agents/issues/runs/approvals/costs/activity; write-queue (serialized, self-healing); heartbeat-loop (порлинг, autocycle-guard, reaper); export/import (redacted).
- Live: broadcastLive → WS + SSE (/api/live-events).
- REST: /api/health, /api/db (GET/PUT blob), /api/debates (заглушка), /api/live-events, M1–M8 (companies: CRUD/heartbeat/agents/chain; costs/budget; issues: tree/checkout/status с gate/escalate; runs: start/get/execute; approvals: list/comment/decide; activity; export/import; adapters: list/test), /api/runs/:id/execute (adapter SDK с budget-gate).

### browser-sidecar.mjs (3100, loopback)

- Playwright driver: /act (open_url, click_at, click_selector, type_text, extract_text_selector/table/schema, scroll, screenshot, extract_text, get_url), /execute (свободный text-задача). SSRF: validateUrl (только http(s) + allowlist BROWSER_USE_ALLOWED_DOMAINS). Auth: опциональный Bearer.

### cors-proxy.mjs (3002)

- CORS-proxy для ?url=; жёсткий origin (CORS_ORIGIN), SSRF через net-guard.mjs (resolveAndCheckHost, блок private IP, allowlist 7 LLM-доменов, DNS-rebinding); срезает чувствительные заголовки; лимит 100MB.
