## 3. `src/routes.tsx` — навигация

- react-router-dom; реестр из `NAV_SECTIONS` (`route-registry.tsx` объединяет CORE+SYSTEM+CONTENT).
- Lazy-loading через `React.lazy` в route-imports.ts (PANEL_COMPONENTS), PanelLoader+ErrorBoundary.
- Алиасы: `/debates/*`, `/diagnostics/*`, `/services/*`, `/chat-admin`, `/timeline`. 404: кастомный.
- Разделы: Dashboard, Budget, Chat, Debates, Debate Strategy, Techniques, Agents, Diagnostics, Wiki, Fleet, Google, Research, Integrations, Randoms, AI Providers, System, Security, Memory, Lab, Other.

## 6. `src/i18n/`

- en/ru, модульные файлы (~20 ns), `loadLocale`, Proxy-переводы, фолбэк, `useTranslation` (useTranslation.ts), тест паритета `i18n-keys.test.ts`.

## 7. Взаимосвязи

```
route-registry-{core|system|content}.ts → NAV_SECTIONS
route-registry.tsx → проверка дубликатов
route-imports.ts → PANEL_COMPONENTS (React.lazy)
routes.tsx → Route path=id element=PanelLoader
src/components/<XxxPanel>/<XxxPanel>.tsx
src/components/<XxxPanel>/<XxxPanel>.test.tsx
```

- id в реестре == ключ в PANEL_COMPONENTS == путь маршрута.
- Тесты: 166 components, 14 stores, 1 i18n, 27 llm, 370 kernel.
- Нюансы: Dashboard отдельно; скрытые маршруты; остаточные ключи секций в route-registry-content.
