# Отчёт сабагента: Оставшиеся группы сервисов (для роадмапов 03/04/05/06/08)

## 1. assistant/ (29)

- Файлы: assistant-service.ts, assistant-agent.ts, assistant-action-registry.ts, assistant-actions.ts, assistant-admin-actions.ts, assistant-ops-actions.ts, assistant-panel-actions.ts, assistant-diary-service.ts, assistant-exam-service.ts, assistant-diagnosis-service.ts, assistant-guide-service.ts, assistant-navigation-service.ts, assistant-view-service.ts, panel-action-registry.ts, project-knowledge-service.ts + ~15 тестов.
- Ключевое: AssistantService — сборка промпта из 4 слоёв знаний (A-документарный, B-структурный, C-эпизодический, D-операционный), пермишен-гейт, цикл runToolLoop, MAX_ROUNDS=5. ProjectKnowledgeService (панель→роут→компонент→тесты). Профили: дневник/экзамен/диагностика/гид/навигация/просмотр.
