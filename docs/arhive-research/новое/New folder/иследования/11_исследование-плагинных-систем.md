# Исследование: Плагинные системы и безопасная изоляция в браузере

## (а) Модели манифеста

| Атрибут     | VS Code (package.json)                      | Chrome MV3                                                      | Obsidian          | n8n                    |
| ----------- | ------------------------------------------- | --------------------------------------------------------------- | ----------------- | ---------------------- |
| id          | publisher.name                              | генерируется из key                                             | id                | name узла              |
| version     | SemVer, обязателен                          | 1.0.0                                                           | SemVer            | version                |
| contributes | contributes (languages/views/commands/... ) | отдельные ключи (content_scripts/action/background/permissions) | регистрация в API | description.properties |
| lifecycle   | activationEvents + activate/deactivate      | service worker                                                  | onload/onunload   | execute()              |
| песочница   | отдельный Extension Host                    | строгая (permissions, запрет удалённого кода)                   | нет жёсткой       | Code node task runners |

Рекомендация: гибрид — манифест от Chrome (строгие permissions + sandbox + запрет удалённого кода), «contributes/жизненный цикл» от VS Code.

## (б) Изоляция стороннего кода в браузере

| Механизм                   | Граница                                       | UI/DOM            | Синхронность                               | Реализуемость       |
| -------------------------- | --------------------------------------------- | ----------------- | ------------------------------------------ | ------------------- |
| iframe+sandbox+postMessage | отдельный browsing context, уникальный origin | полный DOM внутри | асинхронно (postMessage)                   | отлично             |
| Web Worker                 | отдельный поток, нет DOM                      | нет               | асинхронно (postMessage, structured clone) | реализуемо (фон)    |
| ShadowRealm                | отдельный realm, нет DOM/window               | нет               | синхронно (evaluate)                       | Stage 2.7, не везде |
| CSP                        | защита хоста от XSS                           | —                 | —                                          | обязательно         |

Рекомендация: логика/агенты → Web Worker (или ShadowRealm позже); UI/панели → sandboxed iframe (`sandbox="allow-scripts allow-forms"` БЕЗ allow-same-origin) + postMessage RPC с проверкой origin; строгий CSP хоста.

## (в) Регистрация (по образцу VS Code)

Манифест:

```jsonc
{
  "id": "publisher.plugin-id",
  "version": "1.2.0",
  "engines": { "os": "^0.1.0" },
  "activationEvents": ["onTool:search", "onEvent:agent:start"],
  "contributes": {
    "services": [{ "id": "search-provider" }],
    "panels": [{ "id": "main", "entry": "ui/index.html" }],
    "tools": [
      {
        "name": "search",
        "schema": "schemas/search.json",
        "handler": "handlers/search.js",
      },
    ],
    "mcpServers": [{ "name": "my-mcp" }],
    "subscriptions": [
      { "event": "agent:start", "handler": "handlers/onAgentStart.js" },
    ],
  },
  "permissions": ["storage:local", "fetch:https://api.example.com", "ui:panel"],
}
```

## (г) Версионирование/совместимость

- SemVer плагинов + `engines.os` (мин. версия ядра), без `*`.
- Мажорная версия ядра = возможны breaking changes; миграционный слой.
- n8n light/full versioning (typeVersion/@version).
- Proposed API (preview) + feature-flags.

## (д) Риски и контрмеры

| Риск                       | Контрмера                                                                           |
| -------------------------- | ----------------------------------------------------------------------------------- |
| Злонамеренный код          | строгие permissions, минимальные привилегии, изоляция UI/Worker                     |
| Exfiltration/сеть          | allowlist-прокси, запрет произвольного fetch без permission, запрет удалённого кода |
| XSS через UI               | sandboxed iframe без allow-same-origin, строгий CSP, Trusted Types                  |
| Обход sandbox              | не комбинировать allow-scripts+allow-same-origin; проверять event.origin            |
| Неограниченное потребление | таймауты/квоты в Worker, watchdog                                                   |
| Повышение привилегий       | не передавать секреты в контекст плагина; RPC-мост с авторизацией                   |
| Краш ломает приложение     | отдельный Worker/iframe                                                             |
