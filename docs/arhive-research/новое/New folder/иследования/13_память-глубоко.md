## 2. Запись через MemoryService

store() (:419), upsert() (:498), storeBatch() (:577). Поток: passesMemoryQualityGate → computeMemoryId (SHA-256, mem-12hex) → memoryRepo.save (Dexie memories.put) → cache.upsert (кэш 1000) → workerClient.ensure(send('upsert', {generateEmbedding, vector, vectorSpace})).
Таблица Dexie `memories`: схема `'id, content, [metadata.source], [metadata.type], [metadata.timestamp]'`. **vector/metadata.vectorData НЕ индексируются**.
MemoryEntry: id, content, metadata, vector?, vectorData {dimensions, space, model?}.

## 3. Поиск

- search(query, limit=5, mode='auto') (:835): worker готов → send('search', Orama/BM25); mode='semantic'/auto+semanticReady → search_semantic; пустые hits → фолбэк на keyword. Worker недоступен → keywordFilterSearch O(N)-скан (.includes()).
- searchAdvanced(query) (:936): если query.query → search(max(limit*10,100)) затем matchesMemoryQuery; пустой → O(N)-фильтр кэша.
- recall(context, limit=3) (:1079): recallRank — O(N) скан всех записей.

Лимиты: search limit=5; searchAdvanced limit??5, fetch max(limit*10,100); worker limit??5.

## 5. sleep-engine

SleepEngine: recordMutation() (при microCounter>=10 → runMicroConsolidation, только episodic); start() — polling pollIdle(), после 15 мин → runNightlyConsolidation (consolidate всех кроме working → summarizeRecent). **Реальность**: MemoryOrchestrator.start() нигде не вызывается (runtime/bootstrap не стартуют) → ночная консолидация и LLM-summarization фактически не работают; микро-консолидация — только через orchestrator.store() (это делает assistant, phase78-assistant.ts:134). consolidateAll() нигде не вызывается.

## 6. worker-client ↔ memory.worker.ts

MemoryWorkerClient: postMessage {requestId, type, payload} → {requestId, type, payload}; ошибки type:'error'; таймаут 30s. Операции: init, enable_semantic, insert, upsert, remove, search, search_semantic. init: Orama DB (schema id/content/metadata.source|type|timestamp|importance); search → oramaSearch (boost content:2); search_semantic → VectorSpace.match + entries.find (O(N²)). ensure() ленивая; dbReady после init; insert-ответ с embedding → onBackfill (обратная запись вектора). Сериализация: chain.then(handleMessage). Лимиты: MAX_ENTRIES=10000, MAX_VECTORS=10000 (prune FIFO).

## 7. memory-vector-space.ts

VectorSpace: два пространства 'hash' (384 dims) и 'provider' (не смешиваются). hashEmbedding(text, 384) — слово-хеширование + L2. set/get/delete/clear/prune(max) — FIFO. match(queryVec, querySpace) — O(N) скан, cosine, сортировка. **Нет ANN-индекса**.

## 8. WikiBrain

Отдельная БД `aios-wiki-brain` (wiki-brain-dexie.ts:15), таблицы sources/pages/links/log/queue/issues. WikiBrainService — фасад (store/ingest/query/lint/index/log/graph/vault). WikiIndexService.refresh() — генерирует страницы index/overview (НЕ полнотекстовый индекс). WikiQueryService.search() → WikiSearchAdapter: bm25 (O(N) по listPages(limit 10000)), semantic (IEmbeddingPort, вектор-кэш vecs, фолбэк BM25). Векторы страниц — только в оперативке.
