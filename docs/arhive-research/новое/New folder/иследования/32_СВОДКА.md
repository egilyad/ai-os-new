## 2. ТОП-10 самых важных фактов / рисков / инсайтов

1. **Ключи и секреты хранятся открытым текстом** (KeyVault удалён/обходится, deviceKey fail-open, Telegram-токен в agentMemory, ключи в IndexedDB). `06`, `30`, `04dev-status-critical`.
2. **Fail-open в правах**: GovernanceService.evaluate → `allow` при отсутствии совпадения, AgentPermissionService BASE-правила = allow-all, CapabilityResolver.roleToPolicy fail-open. `06`, `28`.
3. **Дебатные стратегии — в основном каталог названий**: DSL-интерпретатора нет; runtime исполняет только топологию (реально ~6 из 33). `05`, `15`, `04`, `31`.
4. **Множество stub/BLOCKED-RUNTIME, маскирующих функциональность**: LLM-судья (token_f1), реранкер, E2B-песочница, дистилляция/миграции/health-SLA (MOCK), деплой, симуляционные агенты (stubAct). `27`, `16`, `26`.
5. **Отсутствует транспортный слой интеграций**: IInteropTransport не реализован, A2A/Федерация/Gateway — только loopback/in-process; внешние коннекторы декоративны. `30`, `10`.
6. **Роутеры/ELO — мёртвый код**: написаны 13 декораторов и роутеры, но управляющего gateway-оркестратора нет; ELO не вызывается; автоматизация маршрутизации не подключена. `20`, `24`, `27`.
7. **Память рассинхронизирована**: 3 независимых контура (MemoryService, WikiBrain, RAG) без общего слоя; лимиты 1000 vs 10000; поиск O(N) без ANN; SleepEngine/summarizer (ночная консолидация) не запускаются. `13`.
8. **«Богатый UI, тонкое ядро»**: 3124 файла vs 582 теста, но test:stable неполный (257 pre-existing падений в 67 файлах), lint-порог захардкожен, низкий coverage. Риск скрытых поломок. `27`, `07`.
9. **Концепция зрелая, но killer-фичи не интегрированы**: 6 уникальных подсистем (дебаты, кристаллы, синтез, конструктор, Time Machine, линзы) плохо связаны между собой, теряются среди 268 панелей; конструктор (Builder) вызывает только 4 типа узлов. `31`.
10. **Главный архитектурный unlock** — превращение Builder в настоящую «IDE» (exposed synthesis/crystal/lens/memory/time-machine как узлы) + восстановление local-first round-trip (import для всех export) + выстраивание cognitive provenance (debate→memory→crystal→synthesis). `31`.

## 4. Рекомендуемый порядок дальнейшей работы

Принцип (из `31`): **не добавлять случайные фичи — закрывать интеграционные пробелы**. Приоритет «критичное→интеграционное→качество».

**Фаза 0 — Безопасность (немедленно, до публичного использования):**

1. Закрыть fail-open: GovernanceService.evaluate, AgentPermissionService, CapabilityResolver, decryptKey (`06`, `28`).
2. Vault: заменить deviceKey на passphrase + Passphrase-UI; at-rest шифрование ключей/секретов (формат `12`), перенос Telegram-токена из agentMemory в vault (`30`).
3. OWASP-приоритет: строгая CSP + рендер как текста, не хранить секреты в system prompt, rate-limit/лимит итераций, grounding+цитаты (`18`).
4. Инструменты/песочница: AST-политика вместо substring-бана, re-check SSRF-redirect, санитизация MCP-fallback, TLS/token для sidecar, включить rateLimit дефолтов (`22`).

**Фаза 1 — Связать «мёртвые» ядра с рантаймом:** 5. Gateway-оркестратор маршрутизации (сейчас роутеры не вызываются) + калибровка (`20`). 6. Движок-интерпретатор дебатных стратегий (DSL → топология+qualitySettings+порядок ходов) (`05`, `19`). 7. Единый слой памяти (синхронизация лимитов, запуск ночной консолидации, ANN-индекс) (`13`).

**Фаза 2 — Интеграция killer-фич (главный unlock, `31`):** 8. Builder как настоящая IDE: exposed synthesis/crystal/lens/memory/time-machine как узлы; connect к 8 killer-сервисам. 9. Восстановить local-first round-trip (import для всех export). 10. Выстроить cognitive provenance: debate→memory→crystal→synthesis двунаправленно.

**Фаза 3 — Транспорт и наблюдаемость:** 11. IInteropTransport + Gateway HTTP ingress/egress + A2A v1.0 клиент (`30`, `10`). 12. Eval-харнесс: реальный LLM-judge, унификация EvalService/EvalDatasetService, CI-гейт evals/ (`26`, `09`).

**Фаза 4 — Качество/долг:** 13. Расширить тест-гейт; покрыть ops/advisor/meta/eval/security; починить полный набор (`07`). 14. UI-рефакторинг (DebatePanel → утилиты → i18n)` тесты) (`21`).
15. Документация: единый gen:wiki-all, детерминизм, SSoT (`29`).

## 5. Что осталось исследовать (лакуны)

1. **Реальный прототип транспортного слоя** — выбрать транспорт (fetch/WebSocket/WebRTC), паттерн безопасности (подпись/верификация пиров, HMAC), OAuth для коннекторов (`30`).
2. **Провайдерная оценка эмбеддингов/реранкинга** — реальный API (не хэш) и кросс-энкодер; калибровка метрик качества (`26`, `13`).
3. **Полный явный «флагманский» сквозной сценарий мультиагентности** — сейчас большинство e2e на дебатах; нет сквозного теста идея→дебаты→исследование→синтез→кристалл→прогноз (`27`, `31`).
4. **Синхронизация между вкладками/устройствами** — crossTabStateSync только на уровне состояния; нужен полный протокол sync (см. `12` CRDT/LWW; разобрать реальное поведение для vault).
