## Ключевые принципы (что важно для этой ОС)

1. **Local-first** — данные живут в IndexedDB/Dexie; «облако» — опционально.
2. **Event-driven** — вся связь через typed EventBus; панели подписываются на события.
3. **Multi-agent / debate-driven** — уникальность в дебатах, кристаллах, синтезе.
4. **Наблюдаемость** — ОС должна уметь объяснить своё состояние.
5. **Модульность** — DI-контейнер + контракты; добавление панели/сервиса должно быть простым.

## Сквозные темы (куда движется проект)

- **От «набора панелей» к «единой рабочей станции»:** меньше панелей, но связанных
  контекстом (одно «исследование» = единая сущность через чат→дебаты→синтез→кристалл→wiki).
- **От «соберём знания» к «качеству знаний»:** provenance, верификация, пересмотр.
- **От «агентов по кнопке» к «управляемой автономии»:** уровни автономности + HITL.
- **От «наблюдаемости-панелей» к «self-explanation»:** единый health/объясни состояние.
