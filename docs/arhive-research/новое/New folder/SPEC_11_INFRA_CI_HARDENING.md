# Спецификация: Закалка CI/инфраструктуры

> Статус: готово к реализации. Приоритет: P1. Связано: `ROADMAP_10`, `PREP_00`.

---

## 1. Выявленные проблемы (факты из кода/CI)

1. **Неполный тест-гейт**: CI гоняет только `test:stable` (scoped), полный `vitest run` не работает (257 pre-existing падений в 67 файлах) — регрессии вне stable-набора проходят.
2. **Lint-порог захардкожен** (`--max-warnings 5600`) — предупреждения не чинятся, лишь «потолок» поднимается.
3. **Coverage-пороги низкие** (30/20%) и include-список узкий.
4. **Docker не тестируется в CI** (нет docker-джобы).
5. **Docs-синхронизация хрупкая**: гейт = «перегенерировал и git diff пустой» (15 генераторов; любая рассинхронизация ломает CI).
6. **Нет автоматического release** (только GitHub Pages; semver вручную; CHANGELOG ручной).
7. Нет CI-проверки «нет битых ссылок» в docs (только docs:health soft).

## 2. Цель

- Надёжный CI: ловит регрессии, не блокирует здоровую работу, публикует релизы.

## 3. Меры

### 3.1 Тесты

- Ввести **каденцию**: быстрый `test:stable` на каждый PR + **ночной полный прогон** (`vitest run`) с публикацией отчёта (чтобы backlog из 257 падений постепенно уменьшался).
- Постепенно расширять `test:stable` (переносить стабильные файлы из полного набора).
- Завести `npm run test:changed` — запуск тестов только для изменённых файлов/зависимостей (для скорости).

### 3.2 Lint / Coverage

- Ввести **lint-гейт по дельте**: новое предупреждение в изменённых файлах → fail (не трогая глобальный «потолок»).
- Поднять coverage-пороги постепенно (пере/35/25) и расширить include (добавить `src/kernel/services/**` по мере покрытия).

### 3.3 Docker

- Добавить CI-джобу `docker build` (сборка образа + smoke-запуск + `docker compose up` + healthcheck).
- Проверять, что образ не содержит секретов (docker history / отпечатки env).

### 3.4 Docs/генераторы

- Уменьшить хрупкость: генерировать wiki в отдельную ветку/артефакт, а в CI проверять **только** «жизненно важные» (manifest + connections + health), а не все 15 diff-ов.
- Либо: сделать гейт «diff только если изменились источники» (проверка путей).
- Починить битые ссылки (см. `ROADMAP_00` Фаза 0.4) — добавить проверку ссылок в `docs:health` (уже есть, распространить на audits/).

### 3.5 Релизы

- Подключить стандартизированный ченджлог из conventional-commits (commitlint уже есть): `release-please` или аналог → automatic semver + CHANGELOG + Git tag + GitHub release.
- Публикация: GitHub Pages (как сейчас) + артефакт `dist` + docker-image на registry.

### 3.6 Прочее

- `--ignore-scripts` убрать из production-пути (или явно документировать).
- Добавить `npm audit` в PR-гейт (уже есть security-audit job — оставить).
- Добавить `dependency-cruiser` + `madge` в локальный pre-push-хук.

## 4. Тесты/проверка

- Локально: `npm run typecheck && npm run lint && npm run test:stable && npm run check:circular-kernel && npm run check:deps`.
- CI-пайплайн после внедрения: все гейты зелёные на main; night-run отчёт виден.

## 5. Definition of Done

- CI гоняет typecheck+lint(дельта)+test:stable+circular+deps+docker+docs:health+audit на PR; ночной полный прогон публикует отчёт; релизы автоматизированы; битые ссылки устранены.
