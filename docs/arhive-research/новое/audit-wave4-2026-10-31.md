## 1. Executive summary (что нового по сравнению с волнами 1–3)

Волна 4 выявила **143 находки** (4 Critical, 40 High, 79 Medium, 20 Low), сгруппированных в 143 сквозных ID `W4-001 … W4-143`. Доминируют пять системных тем:

1. **CI/CD «зелёный, но небезопасный».** CI проходит зелёным, но `deploy.needs: [build, e2e]` — test, coverage, security-audit, circular-check и dep-graph **не блокируют** деплой (W4-001). Параллельно `npm run test:stable` выполняет только ~44 пути из 596 тестовых файлов (~92 % suite молча исключено из gate, W4-002). Шаг upload sourcemaps мёртв из-за GitHub Actions `if: env.X != ''` (W4-005).

2. **Alerting-стек мёртв в рантайме.** `NotificationWebhookService.init()`, `BudgetAlertService.start()`, `MonitoringService.init()` **никогда не вызываются** в production из-за того, что сервисы регистрируются как lazy-factory и материализуются уже после `LifecycleManager.startAll()` (W4-003, W4-004, W4-009). Slack/Telegram-алерты о компрометации ключа, превышении бюджета и деградации агентов молча не отправляются.

3. **AI safety «каркас без оружия».** Tool-output реинжектируется в LLM-цикл с единственной трансформацией `slice(0, 6000)` — без scan/redaction/sanitization (W4-022). Anthropic `cache_control`, OpenAI Moderation, Gemini `safetySettings` **не подключены по умолчанию** (W4-088). Нет topic blocklist (CSAM/self-harm/violence, W4-026). Browser-sidecar `server/browser-sidecar.mjs` слушает на `0.0.0.0:3100` без auth и без URL allowlist (W4-025) — любой, кто дотянется до порта, может водить Chrome.

4. **Cost guards «декларативные, но неисполнительные».** Четыре независимых уровня budget-enforcement (`CostManagerDecorator`, `UsageTracker.checkQuota`, `AgemsBudgetService`, `BudgetAlertService.block_usage`) **ни один не срабатывает на реальном LLM-трафике** (W4-030, W4-031, W4-032, W4-101). Chat-путь не проверяет `canUseProvider`/`canUseGlobal` перед вызовом (W4-031). Race-путь тратит токены всех N кандидатов и double-count-ит spend с flat `$2/M` (W4-103). ToolLoopDetector — мёртвый код; защиту от ping-pong обеспечивает только `maxRounds ≤ 8` (W4-104).

5. **Agent guardrails «дырявые».** `AutonomyRunner.parseAndWriteFiles` пишет файлы в workspace прямо из LLM-вывода, **минуя все 7 approval-сервисов** (W4-042). `autonomy-agent` agentId не зарегистрирован в permission pipeline (W4-043). Preset `AUTOPILOT` даёт FREE по всем destructive операциям без admin-gate (W4-044). Abort-сигнал от UI не доходит до tool-runner (W4-115).

Cross-cutting: `KeyVault` «шифрует» ключи master-ключом, который лежит в `localStorage` в plaintext (W4-020). Восстановление после потери IndexedDB фактически невозможно — `exportToJson` покрывает 16 из 136 таблиц, `db-restore` отсутствует (W4-017, W4-076). 156 продакшн-промптов `"You are..."` лежат в коде без версионирования (W4-041).

По сравнению с волнами 1–3 (которые касались code quality, data integrity, lifecycle/races) волна 4 добавляет инфраструктурный, операционный и AI-safety разрез: CI gate-coverage, deploy safety, secrets lifecycle, alerting/SLO/runbooks, DR, tool-sandbox, cost guards, prompt evals, agent autonomy — системные темы, ранее не рассмотренные.

1. **`chat-send-message.ts:249-265` — chat history sent untruncated per message.** `MAX_HISTORY=200` bounds count, not chars. Losers aborted after winner resolves, но tokens already streamed billable. `budgetService.recordSpend` (`:927`) called only on winner с flat $2/M-token rate — under-counts expensive models. No upfront `canUseProvider`/`canUseGlobal` gate on any candidate.

5. **`computer-use-loop-service.ts:386-488` — up to 30 turns × screenshot accumulation.** Each turn appends assistant message + `tool` message с `inlineData` screenshot up to `COMPUTER_SCREENSHOT_CHAR_LIMIT=3_500_000` chars (~2.6MB base64). 30 × 3.5M = ~105MB image context.
