# T1.3 POST Audit — Привязка агента к ключу/модели в создании

> Дата: 2026-09-09. Scope: рантайм-honor привязки + обе формы создания. Без контрактов/таблиц.

## Проблема
`node.config` уже принимал `model/provider` (spawn пишет `model:'auto'`), но `cognitive-service.evaluateAlternatives` всегда ходил в `router.getRankedProviders` — привязка бы ни на что не влияла.

## Что сделано
1. **Рантайм `cognitive-service.ts`**: `evaluateAlternatives` сначала `resolvePinnedBinding(node)` — если `config.provider` set и ≠'auto', возвращает единственный alternative `{provider, model: config.model||'auto'→SSOT, key: config.keyId→getKey | pool}` score=1. Не резолвится → fallback на роутер (старое поведение). Никогда не бросает.
2. **Тип deps расширен минимально**: `keyService.getKey/selectFromPool` optional — runtime KeyService их уже имеет, DI не меняли.
3. **QuickCreate**: селекты Provider (Auto + active из keys) → Key (пул провайдера) + Model (переписан с мёртвых llama-3.x на SSOT `PROVIDER_DEFAULT_MODELS`); `onCreate` несёт `provider?/keyId?`; View кладёт в spawn config.
4. **AgentWizard**: тот же блок (данные из `useKeyList().activeKeys`) + merge в `spawnArgs.config`.

## Проверки (static)
| Check | Evidence | Result |
|-------|----------|--------|
| Pinned не ломает ротацию | provider пусто/'auto' → `return undefined` → роутер как раньше | ✅ |
| Pinned keyId валидируется | `getKey` + `status!=='error'`, иначе pool, иначе undefined→роутер | ✅ |
| Model default | `'auto'` → `PROVIDER_DEFAULT_MODELS[provider]` | ✅ |
| Guards совместимы | `meta-llama/*` идёт напрямую в `adapterRegistry.getAdapter(provider)` — префиксные гарды только в debate-query-engine, сюда не влияют | ✅ |
| `useKeyList().activeKeys` | `stores/useKeyStore.ts:218` | ✅ |
| Контракты/таблицы/DI | не тронуты | ✅ |

## Как проверить (на твоей машине)
1. Создай агента QuickCreate с Provider=groq, Key=конкретный → открой Topology/Detail — в config `provider/keyId`.
2. Запусти агента → в `COGNITIVE_DECISION_MADE` reasoning `Pinned agent binding`.
3. Создай с Auto → работает как раньше (router).
