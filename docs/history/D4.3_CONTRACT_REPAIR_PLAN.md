## Условие 1) ID mismatch — P0

**Проблема:** `facade:32` `old.createSession → genId council-abc` + `councilToDebateSnapshot.id = council-abc` + `debateEngine.createSession(topology,topic,participants) → genId debate-xyz` игнорирует `snapshot.id`, `getSession 49` fallback маскирует split-brain (`facade:49 always return old.getSession`).

**Ремонт (без кода, дизайн):**

- **Добавить** `IDebateEngine.createSessionWithId(id, topology, topic, participants, language?) : string` (overload, не ломая старый `createSession` — default `id = genId debate` when absent). Альтернатива: `createSession` принимает `opts?:{id?}`.
- **Mapper остаётся pure:** `councilToDebateSnapshot` уже сохраняет `id` same `58` — не менять.
- **Facade `createSession`:** `const debateId = use councilSession.id same (council-abc) → debateEngine.createSessionWithId(councilSession.id, snapshot.topology, ...)`. Не генерировать второй id.
- **Persist `Map<councilId,debateId>` в `keyValue database-service:319` `council:map:<councilId> = debateId`** (на случай если `createSessionWithId` не добавим сразу — тогда map нужен для `getSession` routing). После `createSessionWithId` map = identity (`council-abc→council-abc`), но оставить как migration aid для исторических где уже `debate-xyz` созданы.
- **getSession routing:** `facade.getSession(id) → if keyValue map has debateId → debateEngine.getSession(debateId) else old.getSession(id)` — не `always old`, а `if migrated → DebateStore, else old`. `listSessions` → `Promise.all` both stores with map deduplication (not N+1).
- **Verification:** `round-trip test mapper → createWithId → getSession → assert id same + topic same` (static, no Dexie write until GO).

**Граница:** Не трогать `CouncilService` 5-phase map, не менять `DebateStateMachine` — только id plumbing.

## 4) Facts → arguments (confidence artificial, sources lost)

**Проблема:** Mapper `62` hard-coded `round:0`, `confidence 0.9/0.2/0.5 vs 0.6`, `sources → never citations/evidence`, `whisper filtered`, interleaving lost, `speaker/role/status` not populated (`preflight §3`).

**Ремонт — семантический контракт (без кода, определить поля):**

| Council Fact | Canonical Debate Claim/Argument |
|--------------|----------------------------------|
| `claim` | `text` |
| `verdict verified→0.9, disputed→0.2, unverifiable→0.5` | `confidence` (keep heuristic but **document as heuristic**, not canonical) |
| `sources: string[]` | `citations: string[]` + `evidence: string` (first source as evidence) |
| `authorId` | `agentId` + `speaker` (alias if blind) |
| `author.kind` | `role` |
| `createdAt` | `timestamp` + `round: session.phase==='fact_gathering' ? 0 : session.messages.length` (not hard 0) |
| `channel/toId` (message) | `status: 'active'` + `payload.channel/toId` (not filtered whisper) |

- **Whisper not filtered:** `messages.filter(channel==='forum') 70` → include both `forum|whisper` with `status:'active'` + `payload.channel`.
- **Interleaving:** `facts+messages` → single `arguments[]` sorted by `timestamp` (not facts prepended).
- **Citations:** `FactPacket.sources` → `Claim.citations` + `Claim.evidence = sources[0]`.
- **Round:** `FactPacket` `round` derived from `session.phase` (fact_gathering → 0, debate → current `session.messages.filter(forum).length`), not hard 0.

**Verification:** `submitFact with 2 sources + forum whisper mix → mapper arguments[] length = facts+messages, citations preserved, round correct` (static test pure).

**Граница:** Не делать web grounding (`fetch sources` → `RUNTIME-PENDING` strong PC).

## 5) Judge / Vote / Conclude — главный блокер (проверка из preflight §6)

**Сейчас:** `facade:64` все `submitJudgeScore/castAudienceVote/conclude/abort/postMessage` → `old.*` (old `councilVotes put kind:judge pickId:winnerId 56` + tally `weighted judge.weight??1 359` + audience tie-break `373`).

**Ремонт (минимальный, без второго judging pipeline):**

- **WeightedJudgeEvaluator:** New class `WeightedJudgeEvaluator implements IDebateEvaluator` (`scoreArguments` does `tally Map winnerId→weight` same as `council-service:359`, `rankParticipants` returns `winnerId` sorted). **Alternative to `BayesianJudge` `debate-engine:279` selectable via `topology.metadata.councilMode=true` or `topologyType='council'`** — one `IDebateEvaluator` interface, two strategies (GO constraint: no parallel pipeline).
