## Flag interpretation

- **`UI-HIDDEN` (row 7):** `agent-content`'s outputs ARE written to the shared memory store, but there is no UI or retrieval path that recalls "what Lena previously wrote." Memory is global, keyed by nodeId only as a source tag.
- **`PARTIAL` (row 5):** The curated 📝 avatar is injected into `node.config.avatar` (topology-defaults.ts:103) and is therefore available to identity-aware components, **but** the most-used `AgentAvatar` React component ignores it and derives a deterministic glyph from the id hash (AgentAvatar.tsx:47). So whether Lena shows 📝 depends entirely on which component renders her.
- **`UNUSED` (row 21):** The three specializations are pure metadata. Only `prompt-audit-service.ts:23` (grouping) and the Invocation directory's `specializations` field consume them — neither changes runtime behavior.
- **`DEAD` (row 22):** `cognitive:decision:made` is emitted but has zero subscribers; surfacing content decisions is impossible today.

## Coverage gaps (content-specific)

The agent is named "Content Strategist" with SEO/Messaging specializations, yet **none** of: SEO auditing, editorial scoring, brand-voice consistency, content calendar, publishing, multi-format generation, readability metrics, or A/B messaging are implemented. All 22 capabilities above are either generic agent infra or pure metadata.
