- **Current N+1:** `councilRepository:132` `listSessions → rows.toArray 133 + for r await getSession(r.id) 136 → 2*N queries` (`Promise.all messages+votes where sessionId 82` per session) — `100 sessions → 201 queries`, no limit/pagination, `getSession` re-attaches `facts: vote kind=fact pickId=hashClaim 36 + messages sorted 86`.
- **Plan bulk:** `CouncilMigrationService bulk` → `paginate listSessions` via `offset/limit` (e.g., `20` per batch) + `batch sizing` 20 to respect `HEAP 150/300` `persistence-manager:27` `pruneKeepRounds 3` + `Timeline 5000 cap 11 + persist slice(-500) 62`. Batch 20 → 10 batches for 100, each `Promise.all(mapper→saveSnapshot)` 20 parallel with `MAX_RETRIES 3` `154` backoff `100*2^attempt 186`.
- **Memory limits:** `DebateStore` `arguments stringified` `233` `JSON.stringify(prunedArgs)` where `prunedArgs` heap-aware `84` strips `content` for `round <= maxRound-3` when `HEAP_HIGH 150`, critical `50` items `207`. Bulk batch 20 keeps heap <150.

## 6) Partial failure handling

- Per session `try { migrateOne } catch { rollback(sessionId) 82 → putSession(snapshot) + setKv marker/snapshot null 114 + log }` — single session rollback, not bulk transaction (bulk `transaction rw debateSessions,eventLog` `importFromJson:807` only for import, not for bulk migration — keep per-session `try/catch` to allow 99/100 success).
- `saveSnapshot` failure `validation failed 147` or `version conflict` after 3 retries `173` → `fallback minimal record 263` re-enters `attemptSave` — bulk catches and marks `failedIds`.
- `QuotaExceeded` `Timeline persist slice(-100) 68` fallback.

## 8) Already migrated / malformed / legacy sessions

- **Already migrated:** `getKv council:migrated:${id}` exists → skip (`canMigrate false`).
- **Malformed:** `DebateSessionRecordSchema safeParse 142` fail → `throw validation failed` → `rollback` + `failedIds` + `invalid` in `verifyIntegrity` report `776` sampleErrors.
- **Legacy `fact_gathering` vs `debate` both → `deliberating` lossy `13`:** treat as heuristic, not blocker — document as `lossy, not canonical` (see D4.5c `round heuristic 0`).
