## Что уже есть (факты из аудитов)

- W3-008/027/009: feature-флаги — «точка vs вложенная» структура; `setFeatureFlag` шлёт wrong payload; ConfigOverlays не перезагружают flags.
- W3-028: 4 dead/misleading feature-флага.
- W6-018: feature-flag UI — `as unknown as Record<string, boolean>` (type lie) → тумблеры показывают дефолт (см. Card 20).
- W4-019/033: vault-пассфраза/versioning отсутствуют; перерайты без версии.
- W5-010/013: nginx HTTP-only дефолт; XFF доверие без trusted-proxy (исправлено: SYNC_TRUST_PROXY opt-in).
- W6-002/025: секреты в env (SYNC_SECRET, BROWSER_USE_LLM_API_KEY); unpinned npx в deploy.
- W7-HTTP/Config: настройки размазаны (код/файлы/БД/UI), часть без влияния на поведение.

## Пробелы / риски

- Секреты попадают в env/файлы и не ротируются.
- Флаги реально не влияют на поведение (мёртвые/призраки).
- Дрейф конфигурации между dev/staging/prod.
- Нет единого реестра настроек + поиска по ним.
- Опасные дефолты (unbounded, mockServices включены).

## Рекомендации

1. Единый конфиг-реестр с типизацией и влиянием.
2. Чистка мёртвых флагов; гейт mockServices по умолчанию выключен.
3. Secrets management: не в env/коде, ротация, `.env.example` полный.
4. Валидация дефолтов на безопасность.
5. Поиск/подсказки по настройкам в Settings.
