## Пробелы / риски

- Нет единого search/онбординга по возможностям; Assistant «what can you do?» не раскрыт.
- Долгие агентные задачи выглядят как «ничего не происходит» (нет прогресса).
- Пустые состояния не обучают; терминология различается между панелями.
- Ощущение медленности без скелетонов/оптимистичного UI на ряде путей.

## Рекомендации

1. Скелетоны/оптимистичный UI + индикация этапов долгих задач.
2. Глобальный поиск по настройкам/возможностям.
3. Продолжить a11y-приведение (focus trap, aria-live, кнопки).
4. Единая терминология; обучающие пустые состояния.
5. Онбординг с killer-фичами (Crystal/Synthesis/Builder).
