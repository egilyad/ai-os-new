## Пробелы / риски

- Плагин/хук-механизм слабо формализован (нет стабильного контракта расширения).
- Смена ядра/контракта может сломать сторонние расширения.
- Документация расширения (как добавить панель/сервис) неполная.
- Много «monkey patch»-подходов (as any/as never) снижают предсказуемость.

## Рекомендации

1. Выделить Builder killer-service nodes (расширить palette).
2. Формализовать hooks/plugin-точки + стабильные контракты.
3. Документировать «как добавить панель/сервис» (шаги).
4. Версионировать промпты/расширения.
5. Снизить type-escapes в публичных API.
