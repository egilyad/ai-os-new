## Что уже есть (факты из аудитов)

**Промпты:**

- W4-041: 156 неверсионированных «You are…» промптов в коде (55 файлов) — смена промпта = тихий сдвиг поведения.
- W4-033/034: `prompt-store` перезаписывает overrides без version/author/comment; `prompt-version-service` — localStorage-демо, не привязан к runtime.
- W3-017: `t('...')` со 104 фолбэками `?? 'fallback'` — i18n-пробелы.

**Контекст/память:**

- W2-014: аргументы оппонента из истории дебатов попадают в system prompt (инъекция).
- W8-005: CompressRouteDecorator — opt-in; обрезка контекста молчаливая.
- W8-008: PII/секреты персистятся в долгой памяти до security-скана (исправлено частично: редэкция при записи).
- W3-026: `personaStore.refresh()` не обновляет shared contexts/goals.
- W8-015: recall грузит все воспоминания и перезаписывает `lastAccessedAt` на каждый вызов.

**Маршрутизация/бюджет:**

- W6-008: нет `Idempotency-Key` на LLM-постах → ретраи дублируют платёж/сайд-эффекты (W6-040).
- W4-031: нет pre-call budget-gate в чате (см. Card 17).
- W6-020: race-стратегия молча пропускала tools (исправлено).

## Пробелы / риски

- Нет единого реестра промптов с версиями/авторами (частично есть `prompt-library`).
- Обрезка контекста не объясняется пользователю/модели.
- Память смешивает типы без явного владельца и даты.
- Контекст по цепочке «исследование → дебаты → Wiki» не переносится сквозно.

## Рекомендации

1. `prompt-library`/версионирование для высоконагруженных промптов.
2. Прозрачная обрезка контекста с политикой сжатия.
3. Скоупить память: обязательные `ownerId`+`createdAt`, фильтр по типу.
4. Добавить Idempotency-Key на LLM-вызовы и идемпотентность инструментов.
5. Санитизировать внешний контент до попадания в промпт.
