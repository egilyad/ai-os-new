# 🟡 AUDITS — результаты проверок

Аудиты хранятся как история: каждый — с датой и коммитом, на который смотрел.
Ничего отсюда не является источником текущего состояния.

## Правила

- Имя набора — с датой (`audits-2026-09-18/`); свежий дроп без даты — оформить при коммите.
- Открытые GAPы из аудитов выносятся в один актуальный список (см. роадмап), а не живут в пяти исторических файлах.
- `typecheackerror.md` (2026-09-18): заявления о «0 ошибок / зелёный build» **не воспроизведены** в этой ветке — цитировать только с этой оговоркой.

## Состав

- `_done/audits-2026-07/` — baseline 2026-07-30 (`au1.md` + `audit2/`, 8 файлов), перенесен в готовые.
- `_done/` — все закрытые и исторические аудиты (см. `_done/README.md`).
