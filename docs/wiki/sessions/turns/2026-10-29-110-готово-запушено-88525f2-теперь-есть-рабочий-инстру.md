Готово, запушено `88525f2`. Теперь есть рабочий инструмент:

**Использование:**
```bash
# из файла
npm run session:export -- --title "Тема сессии" --date 2026-10-29 --body path/to/transcript.md

# из stdin
cat transcript.md | npm run session:export -- --title "Тема сессии"
```

Что делает `scripts/export-opencode-session.mjs`:
- создаёт `docs/wiki/sessions/<дата>-<тема>.md` с шапкой по стандарту вики (раздел/статус/теги/агент),
- **автоматически пересобирает индекс** `docs/wiki/sessions.md` (сканирует папку сессий),
- поддерживает `--agent`, `--title`, `--date`, `--body` (файл, либо inline, либо stdin).

Осторожно: CI перегенерирует `docs/wiki` из корпуса `src/components/WikiPanel`. Если сессии лежат в `docs/wiki/sessions/`, следующий `npm run gen:wiki-docs` может их затереть, если они не часть корпуса. Чтобы это гарантированно не трогало сессии, при желании можно:
- повесить сессии отдельно (например `docs/sessions/`) и линковать из вики, или
- добавить `sessions/` в корпус WikiPanel/манифест.
