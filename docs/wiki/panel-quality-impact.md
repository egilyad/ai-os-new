# Панель: Влияние техник

> Раздел: **Панели** · Статус: verified · Теги: панель, качество, эксперименты, экспорт, инструкция

Источники: `src/i18n/translations/en/quality.ts`, `src/components/QualityImpactDashboard/QualityImpactDashboardPanel`

## Назначение

Оценка влияния техник на результат. Ключи `quality_impact.*`.

## Метрики

Сессии, техники, срабатывания, доля положительных, дельта, число применений и уверенность. Вклад оценивается по последнему касанию (last_touch) и по частоте.

## Эксперименты

Создание и запуск эксперимента (имя, число сессий), прогресс, статус, остановка и удаление; список экспериментов.

## Экспорт

Экспорт в JSON и CSV (метрики, сессии, бейзлайны); копирование JSON с уведомлением.

## Где менять

Компонент: `QualityImpactDashboardPanel`. Датасеты — [Панель: Датасеты оценки](./panel-eval.md), аналитика — [Панели: Аналитика, затраты и ключи](./panel-analytics.md).
