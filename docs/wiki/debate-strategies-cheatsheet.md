# Дебаты: шпаргалка стратегий (33)

> Раздел: **Дебаты** · Статус: verified · Теги: дебаты, стратегии, шпаргалка, схемы

Источники: `src/kernel/services/debate-runtime/debate-strategy-definitions.ts`

## Назначение

Полная шпаргалка по встроенным стратегиям дебатов. У каждой — суть, схема (упрощённая) и когда использовать.

## Классические

- **Round Robin** — Pro ↔ Con по очереди, каждый раунд по одному ходу. · Простой спор двух сторон.
- **Moderated** — Модератор (neutral) управляет: Pro → модератор → Con → модератор. · Управляемый спор с правилами.
- **Free-for-All** — много агентов говорят одновременно, без строгого порядка. · Живой, хаотичный срез мнений.
- **Spontaneous Argumentation** — спонтанные реплики без заранее заданной структуры. · Эспромт-обсуждение.
- **Trial by Argument** — «суд аргументами»: обвинение/защита и вердикт. · Формальный спор с вынесением решения.

## Философские / аналитические

- **Socratic** — Вопрос-ответ цикл: Questioner задаёт вопросы, Claimant отвечает, пока не согласие. · Вскрытие допущений.
- **Argument Tree** — Тезис ↔ Антитезис → Синтез (дерево вызовов и уточнений). · Глубокий структурированный анализ.
- **Meta-Debate** — спор о самом споре: правила, качество, полнота. · Рефлексия над процессом.
- **Rhetorical Triangle** — анализ с позиций этоса/логоса/пафоса (говорящий/логика/эмоции). · Убедительность речи.
- **Uncertainty Quantification** — оценка уверенности/неопределённости утверждений. · Где данных мало.

## Проверка идей

- **Hypothesis Testing** — сформулируй гипотезу и проведи её через спор/данные. · Проверка идей.
- **Premortem** — представь, что решение уже провалилось, и найди причины. · Проактивное выявление рисков.
- **Post-Mortem / Autopsy** — разбор уже случившегося провала. · Уроки из прошлого.
- **Red Teaming** — «красная команда» атакует решение, «синяя» защищает. · Стресс-тест решения.
- **Scenario Testing** — прогон решения по сценариям. · Устойчивость к ситуациям.
- **Cross-Examination** — перекрёстный допрос: прямые вопросы, требующие точных ответов. · Проверка слабых мест.

## Коллективные

- **Brainstorming** — свободная генерация идей без критики. · Сбор идей.
- **Delphi Method** — анонимные раунды оценок + обратная связь, сходимость к консенсусу. · Экспертная оценка.
- **Collaborative Consensus** — совместный поиск согласия, а не спор. · Консенсус.
- **Asynchronous Marathon** — длинный асинхронный обмен аргументами. · Медленное глубокое обсуждение.
- **Flash Debate** — короткий быстрый обмен репликами. · Быстрая проверка позиций.
- **Debate-athon** — марафон из множества коротких дебатов. · Серийное сравнение тем.
- **Contest Mode** — соревновательный режим с баллами и победителем. · Турнир/соревнование.

## Структурированные / профессиональные

- **Constrained** — спор по строгим правилам: автор → рецензенты, критерии, правки. · Качество аргументации.
- **Jury Trial** — «жюри» оценивает аргументы сторон. · Коллегиальная оценка.
- **Evidence-Based Policy** — только на доказательствах, заданный уровень доказательности. · Политика/факты.
- **Multi-Criteria Decision Analysis** — решение по нескольким критериям. · Сложный выбор.
- **Stakeholder Mapping** — рассмотрение с позиций всех заинтересованных сторон. · Влияние решения.
- **Principle-Based Negotiation** — переговоры по принципам, а не позициям. · Взаимовыгодные договорённости.
- **Simulated Negotiation** — симуляция переговоров между сторонами. · Подготовка к переговорам.
- **Parliamentary** — парламентский регламент: правительство/оппозиция, вопросы. · Формальные дебаты.
- **Oxford Union** — формат Оксфорда: «за»/«против» + голосование зала. · Классическое выступление.
- **Lincoln-Douglas** — дуэль ценностей: логика и этика, тайм-менеджмент. · Ценностный спор.

## Как выбрать

Если не знаешь, с чего начать — **Round Robin** или **Moderated**. Для проверки идеи — **Socratic / Red Teaming / Hypothesis Testing**. Для решения — **Multi-Criteria / Stakeholder Mapping**.
