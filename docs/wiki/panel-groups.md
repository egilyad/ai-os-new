# Панель: Группы ключей

> Раздел: **Панели** · Статус: verified · Теги: панель, группы, ключи, инструкция

Источники: `src/i18n/translations/en/providers.ts`, `src/components/GroupsPanel/GroupsPanel.tsx`

## Назначение

Группировка ключей по пулам и балансировка. Ключи `groups.*`.

## Возможности

Создание, переименование и удаление группы (с подтверждением), число ключей, перемещение ключей между группами (включая «без группы»), распределение ключей и авто-балансировка пулов. Есть предупреждение по умолчанию и подсказка выбора.

## Где менять

Компонент: `GroupsPanel`. Пул ключей — [Панель: Пул ключей провайдеров](./panel-pools.md), ротация — [Панель: Ротация ключей](./panel-rotations.md).
