# Панель: Диада

> Раздел: **Панели** · Статус: verified · Теги: панель, диада, дебаты, инструкция

Источники: `src/i18n/translations/en/dyad.ts`, `src/components/DyadPanel/DyadPanel.tsx`

## Назначение

Диалог двух ролей (пользователь и ассистент) на заданную тему. Ключи `dyad.*`.

## Как пользоваться

Список диад (со статусами running / completed / stuck / failed / aborted), открытие по идентификатору, запуск по теме с выбором ролей пользователя и ассистента.

## Лог и результат

Есть лог выполнения и результат; тема обязательна (валидация), при отсутствии — `notFound`.

## Где менять

Компонент: `DyadPanel`. Обзор дебатов — [Дебаты: режимы и механика](./debates.md), групповой чат — [Панель: Групповой чат](./panel-group-chat.md).
