# Панель: Шаблоны дебатов

> Раздел: **Панели** · Статус: verified · Теги: панель, дебаты, шаблоны, инструкция

Источники: `src/i18n/translations/en/debate.ts`, `src/components/DebateTemplatesPanel/`, `src/components/DebatePanel/DebateWorkspacePanel`

## Назначение

Библиотека готовых шаблонов дебатов. Ключи `debate.templates*`.

## Шаблоны

Готовые сценарии: code-review, ADR, post-mortem, оптимизация промпта. Есть поиск, счётчик, применение шаблона, а также поля участников и числа раундов.

## Рабочее пространство

`DebateWorkspacePanel` — рабочее пространство для сборки дебата.

## Где менять

Компоненты: `DebateTemplatesPanel`, `DebateWorkspacePanel`. Турнир — [Панель: Турнир дебатов](./panel-debate-tournament.md).
