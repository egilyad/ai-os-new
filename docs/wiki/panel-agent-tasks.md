# Панель: Задачи агентов

> Раздел: **Панели** · Статус: verified · Теги: панель, задачи, инструкция

Источники: `src/components/AgentTasksPanel/AgentTasksPanel.tsx`

## Назначение

Создание задач, композитор (обычный / browser / computer режимы), история запусков с итогами.

## Как запустить задачу

1. Выбери агента и опиши задачу.
2. Для browser/computer понадобится sidecar и человеческий approve (computer-use без approve не стартует).
3. Следи за статусом: queued → running → completed/failed/cancelled.

## Где след

Каждый запуск пишет строку ProjectRun (задача → запуск → вызовы → итог), вызовы инструментов — в общий журнал. См. [След исполнения: журнал, раны, зомби](./execution-trail.md).
