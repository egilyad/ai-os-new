# Из документов в навыки агентов

> Раздел: **Разработчикам** · Статус: verified · Теги: dev, навыки, документация, wiki

Источники: `scripts/gen-skill-from-docs.mjs`, `src/kernel/services/skills/skill-spec.ts`, `docs/STRUCTURE.md`

## Идея

Документ сам по себе — пассивный актив. **Навык (Skill)** — это активная инструкция: агент загружает
только то, что нужно для текущей задачи, а не всю документацию целиком. Превращение `docs/**` в
навыки замыкает цикл: документация → компетенция агента → результат → обновлённая документация.

## Как это работает в ОС

Генератор `scripts/gen-skill-from-docs.mjs` (npm-скрипт `gen:skill-from-docs`) принимает набор
Markdown-документов и создаёт каталог навыка:

- `SKILL.md` — frontmatter (`name`, `description` ≤ 60 символов, `version`, `tags`) и процедурные шаги;
- `Chapters/*.md` — главы, загружаемые **по требованию** (не весь текст в контексте);
- `Patterns.md` — повторяющиеся решения и шаблоны;
- `Cheatsheet.md` — таблица «тема → глава → исходный файл».

Каждая глава сохраняет путь к исходному документу — агент может раскрыть цитату до оригинала.

### Пример вызова

```bash
npm run gen:skill-from-docs -- \
  --name superagents-architecture \
  --description "Explains SuperAgents OS architecture to agents" \
  --docs docs/01-system-architecture.md docs/STRUCTURE.md docs/wiki/dev-overview.md \
  --out .superagents/skills/superagents-architecture
```

Результат проверяется нашим же парсером `parseSkillMarkdown()` из
`src/kernel/services/skills/skill-spec.ts` — формат совместим с агентными средами, которые
понимают Agent Skills.

## Зачем это нужно

- **Экономия контекста:** агент читает индекс и одну главу вместо 500 страниц.
- **Переиспользование:** один и тот же навык подключается к разным проектам и агентам.
- **Прослеживаемость:** каждая глава ссылается на исходный файл в репозитории.
- **Замкнутый цикл:** результат работы агента попадает в документацию → навык пересобирается.

## Куда складывать

Готовые навыки живут в `.superagents/skills/<name>/` рядом с памятью и правилами ОС.
Для project-уровня полезно хранить ссылку на такой каталог как на артефакт проекта — рядом
с отчётами дебатов и экспортом Topic Graph (`TopicResults/`).

## Ограничения

- Сейчас генератор детерминированный: он структурирует заголовки, а не «понимает» смысл.
  Для смысловой упаковки можно подключить LLM из ОС через существующий конвейер Wiki-Brain.
- Формат `SKILL.md` предполагает, что шаги ссылаются на нативные инструменты агента
  (`read_file`, `patch`), а не на произвольный shell.
