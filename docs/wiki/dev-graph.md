## Поиск и переходы

- Полнотекстовый поиск — на сайте `/wiki/` и в панели Wiki; фильтры по разделам.
- Переходы «сущность → сущность» — из этого графа и `docs/graph.json`.
- Плоский машинный индекс — `docs/manifest.json` ([Инвентаризация документации](./docs-inventory.md) описывает состав).

## Как это считается

- Узлы и связи берутся из `docs/manifest.json` (статьи, панели, источники, тесты, related).
- `related` добавляется только для существующих статей; дубликаты рёбер удаляются.
- Источник: `scripts/gen-docs-graph.mjs` → `docs/graph.json` → эта страница.
