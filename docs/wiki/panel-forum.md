# Панель: Форум

> Раздел: **Панели** · Статус: verified · Теги: панель, форум, обсуждения, инструкция

Источники: `src/i18n/translations/en/analytics.ts`, `src/components/ForumPanel/ForumPanel.tsx`

## Назначение

Внутренний форум обсуждений между темами, постами и голосами. Ключи `forum.*`.

## Топики

Список тем с категориями и фильтром, системные темы, посты. Есть сид-демо.

## Действия

Модерация, голоса вверх / вниз, закрепление (pin / unpin), экспорт темы в markdown и эскалация спорных тем в дебаты (можно только спорные).

## Где менять

Компонент: `ForumPanel`. Дебаты — [Дебаты: режимы и механика](./debates.md), исследование — [Панель: Исследовательский движок](./panel-research.md).
