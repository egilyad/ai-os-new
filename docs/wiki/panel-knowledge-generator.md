# Панель: Генератор знаний

> Раздел: **Панели** · Статус: verified · Теги: панель, генератор, знания, инструкция

Источники: `src/i18n/translations/en/analytics.ts`, `src/components/KnowledgeGenPanel/KnowledgeGenPanel.tsx`

## Назначение

Автоматическая генерация знаний по типам заданий. Ключи `generator.*`.

## Типы заданий

По расписанию (scheduled), аномалия, пробел (gap), вопрос форума, конфликт кристаллов и кросс-доменное.

## Ход

Запуск и отмена задания, список активных задач. Стадии: гипотеза → доказательства → ревью → кристаллизация → готово. Статусы queued / running / completed / failed / cancelled; показываются уверенность и токены. Есть сид-демо.

## Где менять

Компонент: `KnowledgeGenPanel`. База знаний — [Панель: База знаний (RAG)](./panel-knowledge.md), кристаллы — [Панели: Линзы и кристаллы](./panel-lenses-crystals.md).
