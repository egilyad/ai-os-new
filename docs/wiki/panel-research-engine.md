# Панель: Исследовательский движок

> Раздел: **Панели** · Статус: verified · Теги: панель, исследование, research, движок, инструкция

Источники: `src/components/ResearchPanel/ResearchEnginePanel.tsx`, `src/kernel/services/research/`

## Назначение

Исследовательский движок — базовый цикл исследования: создаёшь сессию с вопросом, добавляешь источники и запускаешь цикл поиска/анализа.

## Как пользоваться

1. Открой `/research-engine`.
2. «Новая сессия»: название + вопрос.
3. Добавь источники.
4. Нажми «Запустить» (`runLoop`) — агент прогонит цикл по вопросу.
5. При необходимости удали/перезапусти сессию.

## Связи

Результаты оформляются в [Панель: Отчёты исследований](./panel-research-reports.md), гипотезы проверяются в [Панель: Генератор гипотез](./panel-hypothesis-generator.md), продвинутая версия — [Панель: Исследования — расширенные](./panel-research-advanced.md).
