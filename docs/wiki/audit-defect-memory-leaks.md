# Аудит: класс дефектов — утечки памяти/ресурсов

> Раздел: **Разработчикам** · Статус: verified · Теги: аудит, память, утечки, ресурсы, дефекты

Источники: `src/kernel/`, `src/components/`, `src/hooks/`

## Назначение

Аудит на утечки памяти и ресурсов: таймеры, слушатели событий, подписки, workers, http-запросы, DOM-узлы, кэши.

## Что искать

- setInterval/setTimeout без очистки (в т.ч. при unmount).
- Подписки на eventBus/сторы без отписки.
- Накопление в кэшах/библиотеках без лимитов.
- Не отменённые AbortController/запросы.
- Ссылки, удерживающие большие объекты (буферы, массивы).

## Связи

Класс часто соседствует с [Аудит: класс дефектов — гонки/жизненный цикл/async cleanup](./audit-defect-race-lifecycle.md). Выявлять системно через [Аудит: методология и процесс](./audit-methodology.md).
