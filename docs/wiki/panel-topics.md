# Панель: Генератор тем

> Раздел: **Панели** · Статус: verified · Теги: панель, темы, генератор, инструкция

Источники: `src/i18n/translations/en/debate.ts`, `src/components/TopicSuggesterPanel/`

## Назначение

Предложение тем для дебатов. Ключи `topic_suggester.*`.

## Возможности

Фильтры по категориям, исключения, число тем, своя тема (custom), копирование темы, обновление и сброс фильтров. Пустое состояние честное.

## Где менять

Компонент: `TopicSuggesterPanel`. Дебаты — [Дебаты: режимы и механика](./debates.md), шаблоны — [Панель: Шаблоны дебатов](./panel-debate-templates.md).
