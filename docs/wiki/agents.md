# Агенты: устройство и управление

> Раздел: **Агенты** · Статус: documented · Теги: агенты, персоны, политики

Источники: `src/kernel/agents/registry.ts`, `src/kernel/services/agent-service.ts`, `src/kernel/services/permissions/permission-service.ts`

## Что есть

Реестр из 15 встроенных агентов (исследователь, риск, архитектор и др.) + спавн своих: имя, системный промпт, температура, модель, инструменты. Топология переживает перезагрузку.

## Агентные каркасы

Четыре агента перенесены из внешних каркасов и доступны в админке наравне с остальными: «Кодовый исполнитель» (opencode), «Навыковый агент» (hermes), «Агент-воронка» (deepseek-harness), «Оркестратор роя» (openclaw). Каждый приносит свою специализацию: точечные патчи, навыки с делегированием, водопад инструментов, swarm-оркестрация.

## Управление

Создание, пауза, рестарт, удаление — через сервисы (программно доступно внутреннему менеджеру). Задачи: создание, claim с TTL, статусы. Политики ограничивают провайдеры/модели на агента; computer-use требует человеческого approve.

## Разрешения и инструменты

У каждого агента есть режим доступа (read-only / guarded / workspace / full) и профиль инструментов (minimal / research / coding / full). Правила разрешений собираются из базового набора, пресета режима, защиты секретов, правил агента и сохранённых правил; срабатывает последнее совпавшее правило. Вызовы инструментов проходят водопад: пре-фаза (разрешение) → тело → пост-фаза (приём/обогащение/блокировка).

## Ограничения

Единого источника задач нет (Dexie-задачи, in-memory автономки, очереди). RBAC нет — single-user дизайн, учитывай при доступе.
