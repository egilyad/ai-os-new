# Мультиагентные ИИ-ОС: аналитический обзор и карта редких паттернов

> Цель: определить редчайшие и наиболее полезные компоненты/паттерны мультиагентных ИИ-ОС и фреймворков, применимые к SuperAgents OS.
> Метод: аналитический обзор открытых архитектур (без API-запросов). Границы: многоагентные фреймворки, «агентные ОС», субагентные режимы и исследовательские системы.

## 3. Топ-8 редких паттернов, которые стоит внедрить

По сочетанию «редкость × полезность для нам»:

1. **Claim-centric evidence** — сделать выводы строго из проверяемых утверждений с цитатами (Crystal Vault → од разработки).
2. **Record a Skill / процедурная память** — превращать удачные цепочки действий в повторяемые навыки.
3. **Blackboard / Global Workspace** — общий «фокус внимания» для агентов вместо разрозненного контекста.
4. **Sub-agent spawn с изоляцией** — запуск субагентов со своим контекстом и бюджетом.
5. **Cross-session memory consolidation** — фоновая консолидация и забывание.
6. **Sandbox с отрезанной сетью** — защита выполнения кода.
7. **Long-horizon state machine с checkpoint/resume** — переживание перезагрузки.
8. **Multi-agent debate с ограничением семейств** — снижение подстройки и предвзятости судей.

## 4. Что в SuperAgents OS уже сильно (не нужно «изобретать»)

- **Дебаты**: 33+ стратегии, живые графы, вердикты — это уже целевая зона поверх многих фреймворков.
- **Crystal Vault + Junction + Synthesis**: ядро claim-центричной работы уже заложено.
- **Маршрутизация UCB1/broadcast/race** и декораторы (circuit breaker, retry, rate-limit, cost manager).
- **Знаниевый конвейер** и гибридный поиск (BM25 + семантика).

## 6. Вывод

Мультиагентные ИИ-ОС уже выработали несколько «редких» паттернов, которых у SuperAgents OS пока нет, но которые дают наибольший рывок в глубине и надёжности. Лучший ROI — **claim-centric evidence**, **процедурная память (навыки)** и **песочница**. При этом значительная часть фундамента (дебаты, Crystal Vault, маршрутизация) уже сильнее, чем у большинства открытых систем — поэтому усилия стоит вкладывать не в «догнать», а в «замкнуть цикл» и «углубить доверие».
