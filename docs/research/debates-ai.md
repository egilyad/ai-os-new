# Исследование: дебаты ИИ

> Тема: как устроены мультиагентные дебаты языковых моделей, стратегии, арбитраж, вердикты, анти-сговор и оценка. Что из этого стоит усилить в SuperAgents OS.

## 1. Зачем дебаты ИИ

Дебаты — один из самых сильных способов «вытащить» из LLM более надёжный ответ: несколько моделей/ролей спорят, и вердикт выносится на основе аргументов. Это снижает галлюцинации и увеличивает покрытие точек зрения.

## 2. Ключевые подходы (из литературы и практики)

| Подход                                 | Идея                                      | Сильная сторона                    |
| -------------------------------------- | ----------------------------------------- | ---------------------------------- |
| Multi-Agent Debate (Du et al.)         | Несколько LLM обсуждают; итог — консенсус | Рост качества на reasoning-задачах |
| Society of Minds                       | Раздельные «мыслители» + агрегация        | Диверсификация мнений              |
| Debatrix                               | Вердикт через судью/арбитра               | Структурный арбитраж               |
| Delphi/Parliamentary (в нашем проекте) | Многоформатные стратегии                  | Уже реализовано                    |

## 3. Стратегии дебатов

- Round-robin, свободный обмен, модератор.
- Сократический, аргументное дерево, перекрёстный допрос.
- Слепой первый раунд (без доступа к чужим ответам) — против подстройки.
- Разделение ролей: proponent/opponent/mediator/observer.
- Ограничение: модели в одном дебате — из разных семейств (анти-сговор).

## 4. Арбитраж и вердикт

- Судья (отдельная модель, не участник).
- Эвристический вердикт (по силе аргументов, цитатам, согласию).
- Несколько судей + уровень согласия (inter-judge agreement).
- Учёт «длины ответа» и «семейства модели судьи» (не судить своё семейство).

## 5. Анти-сговор и предвзятость

- Слепые раунды, скрытые имена.
- Разные семейства моделей.
- Дублирование вердикта с переставленными сторонами (swap-test).
- Выравнивание длины ответов сторон.
- Мониторинг «согласия участников» (матрица согласия) — если все всегда соглашаются, это подозрительно.

## 6. Оценка качества дебатов

- Качество вердикта против ground-truth.
- Faithfulness: поддерживают ли цитаты утверждения.
- Покрытие: сколько точек зрения затронуто.
- Экономика: токены/деньги на достигнутое качество.
- Ранняя остановка по сходимости (когда позиции сошлись, дальше копать не нужно).

## 7. Что в SuperAgents OS уже есть (и усиливать не надо)

- 33+ встроенных стратегии дебатов.
- Живая арена, интерактивные графы аргументов.
- Вердикты, метрики качества, человеческий вклад.
- Юрий/Parliamentary/Delphi и др.

## 8. Что стоит добавить/усилить (паттерны)

| Паттерн                                         | Зачем                       | Статус                |
| ----------------------------------------------- | --------------------------- | --------------------- |
| Запрет одного семейства у участников/судей      | Меньше подстройки           | Нет                   |
| Слепой первый раунд                             | Против подстройки           | Нет                   |
| Swap-test (вердикт с переставленными сторонами) | Проверка предвзятости судьи | Нет                   |
| Матрица согласия участников                     | Видно сговор                | Частично (DebateLens) |
| Ранняя остановка по сходимости                  | Экономия токенов            | Есть (governor)       |
| Отдельный судья + inter-judge agreement         | Надёжность вердикта         | Частично              |
| Faithfulness-проверка цитат в аргументах        | Доверие                     | Нет                   |

## 9. Вывод

SuperAgents OS уже очень сильна в дебатах. Главные редкие дополнения — **ограничение семейств**, **слепые раунды**, **swap-test** и **inter-judge agreement**. Это небольшие, безопасные изменения, дающие заметный прирост надёжности вердиктов.
