# Исследование: сложные темы в мультиагентных системах

> Тема: как с помощью нескольких агентов исследовать сложные, многогранные темы (несколько перспектив, дебаты, синтез, противоречия). Что усилить в SuperAgents OS.

## 1. Почему мультиагентность помогает исследованию

Сложная тема редко имеет одну «правильную» точку зрения. Несколько агентов с разными ролями/перспективами дают:

- покрытие разных углов,
- выявление противоречий,
- более взвешенный синтез,
- меньше предвзятости одной модели.

## 2. Ключевые паттерны

| Паттерн                        | Суть                            | Редкость | Статус у нас         |
| ------------------------------ | ------------------------------- | -------- | -------------------- |
| Мульти-перспективный синтез    | Разные роли → единый вывод      | Средняя  | Есть (Synthesis)     |
| Дебаты как метод исследования  | Аргументация по теме            | Низкая   | Есть (33+ стратегии) |
| Contradiction resolver         | Взвешивание противоречий        | Высокая  | Частично (Junction)  |
| Эксперты-свидетели             | Отдельные «экспертные» агенты   | Средняя  | Частично             |
| Иерархия вопросов              | Дерево/DAG подвопросов          | Высокая  | Нет                  |
| Ранняя остановка по сходимости | Экономия                        | С-я      | Есть (governor)      |
| Резюме с цитированием          | Каждое утверждение с источником | Высокая  | Частично             |
