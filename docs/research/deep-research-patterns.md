# Исследование: создание сложных исследований ИИ

> Тема: как строить глубокие автономные исследования (Deep Research): планирование, субагенты, evidence, синтез, конвергенция. Что усилить в SuperAgents OS.

## 1. Что отличает «сильный» research от «слабого»

- **Claim-centric**: утверждения + доказательства — first-class сущности (а не «пересказ текста»).
- **Планирование**: разбиение на подвопросы, часто в виде DAG (зависимости веток).
- **Параллелизм**: независимые ветки идут одновременно (субагенты).
- **Дедупликация**: источники не повторяются.
- **Конвергенция**: остановка по маргинальной отдаче, а не по фиксированному числу шагов.
- **Проверка**: faithfulness (цитата поддерживает утверждение), coverage, contradiction handling.
- **Прозрачность**: каждое предложение вывода опирается на источник.

## 2. Ключевые паттерны

| Паттерн                 | Суть                             | Редкость | Статус у нас                      |
| ----------------------- | -------------------------------- | -------- | --------------------------------- |
| Claim-centric evidence  | Утверждения + цитаты             | Высокая  | Частично (Crystal Vault)          |
| DAG-план подвопросов    | Граф зависимостей                | Высокая  | Нет (идут последовательные loops) |
| Субагенты с бюджетом    | Параллельный сбор                | Высокая  | Нет                               |
| Дедупликация источников | URL + content hash               | Средняя  | Есть (недавно)                    |
| Конвергенция            | Стоп по отдаче                   | Высокая  | Частично                          |
| Faithfulness-проверка   | Цитата поддерживает claim        | Высокая  | Нет                               |
| Citation-агент          | Отдельный сбор/оформление ссылок | Высокая  | Нет                               |
| Критик с budget-cutoff  | Точечные доборы                  | Высокая  | Нет                               |

## 3. Что в SuperAgents OS уже есть (не дублировать)

- Research Engine (цикл вопрос → источники → анализ).
- Crystal Vault + Junction + Synthesis (claim-центричная база).
- Дедупликация источников (недавно добавлена).
- Планирование следующего вопроса из всех follow-up.
- Research Cockpit (запуск, процессы, покрытие).

## 4. Что стоит добавить (редкое, не дублирующее)

| Приоритет | Паттерн                     | Зачем                    | Объём   | Риск    |
| --------- | --------------------------- | ------------------------ | ------- | ------- |
| Высокий   | Faithfulness-проверка цитат | Доверие к выводам        | Средний | Низкий  |
| Высокий   | DAG-план подвопросов        | Параллельность и глубина | Большой | Высокий |
| Средний   | Субагенты с бюджетом        | Параллельный сбор        | Большой | Средний |
| Средний   | Критик с budget-cutoff      | Точечные доборы          | Средний | Средний |
| Средний   | Citation-агент              | Аккуратные ссылки        | Средний | Низкий  |

## 5. Вывод

У нас уже сильная база (claim-centric через Crystal Vault, дедупликация, планирование). Самые ценные добавления — **faithfulness-проверка** (дешёво, важно) и **DAG-план** (крупно, даёт настоящую глубину). Субагенты и критик — следующий уровень.
