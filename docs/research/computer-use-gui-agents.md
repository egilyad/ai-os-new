# Исследование (сессия 3): Computer Use / GUI-агенты

> Тема: как устроены агенты, управляющие произвольным GUI через «зрение + клики» (Claude Computer Use, OpenAI Operator, OSWorld-подобные). Сложности и как это применить.

## 1. Что такое Computer Use

Агент смотрит на экран (скриншоты) и выдают действия: движение мыши, клики, ввод текста, скролл, комбинации клавиш. Работает с любым GUI, а не только с браузером.

## 2. Ключевые реализации

| Реализация               | Что делает                                  | Особенности                        |
| ------------------------ | ------------------------------------------- | ---------------------------------- |
| Claude Computer Use      | API «computer use tool» — зрение + действия | Скриншот → действия; цепочки шагов |
| OpenAI Operator          | Агент в браузере, выполняет задачи          | Мульти-шаговые сценарии            |
| OSWorld                  | Бенчмарк компьютерных агентов               | Оценка реальных задач в ОС         |
| Screen agents (research) | Скриншоты + координаты + действия           | Общий паттерн                      |

## 3. Общий паттерн «зрение + клики»

1. Захват скриншота экрана.
2. LLM (vision) анализирует: что видно, какая цель, где элемент.
3. Модель возвращает действие: `click(x,y)`, `type(text)`, `scroll`,` `key(...)`.
4. Среда выполняет действие.
5. Повтор (цикл) до завершения задачи.

## 4. Сложности

| Сложность             | Описание                     | Митигация                                      |
| --------------------- | ---------------------------- | ---------------------------------------------- |
| Координаты            | Пиксельные координаты хрупки | Использовать центры элементов, масштабирование |
| Разные разрешения/DPI | Координаты плавают           | Нормализация, относительные координаты         |
| Динамический UI       | Меняется после каждого шага  | Частые скриншоты, повторный анализ             |
| Скорость/стоимость    | Vision-модель дорогая        | Выборочный анализ, кэширование                 |
| Безопасность          | Опасные действия             | Разрешения, аудит, блокировка                  |
| Ошибки клика          | Промахи                      | Retry, подтверждение, fallback на DOM          |

## 5. Что применить в SuperAgents OS

- **Гибрид**: в браузере использовать DOM/accessibility (дёшево), а для любого GUI — computer use (зрение+клики).
- **Цикл скриншот→действие**: выделить как отдельный сервис (ComputerUseAgent).
- **Валидация координат**: перед кликом — проверка, что цель на месте (повторный анализ при сомнении).
- **Aудит**: каждая пара «скриншот→действие→результат» сохраняется.

## 6. Вывод

Computer Use — мощный, но дорогой и хрупкий. В SuperAgents OS оптимально: **браузер через DOM/accessibility + визуальный fallback**, а **computer use — для произвольного GUI** как отдельный сервис с жёсткими разрешениями и аудитом.
