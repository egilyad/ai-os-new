# Исследование: память ИИ

> Тема: как устроена память в ИИ-ОС и агентах (эпизодическая/семантическая, долговременная, рабочая, консолидация, RAG, забывание, blackboard). Что усилить в SuperAgents OS, не дублируя уже имеющееся.

## 1. Типы памяти

| Тип               | Суть                               | Где чаще используется       |
| ----------------- | ---------------------------------- | --------------------------- |
| Рабочая (working) | Текущий контекст задачи            | Все агенты                  |
| Эпизодическая     | «Что произошло» (события, диалоги) | Память сессий               |
| Семантическая     | «Что известно» (факты, знания)     | База знаний                 |
| Процедурная       | «Как делать» (навыки, процедуры)   | Редко (Codex/Claude skills) |
| Проспективная     | «Что сделать позже» (напоминания)  | Редко                       |

## 2. Ключевые паттерны

| Паттерн                              | Суть                                          | Редкость | Статус у нас                |
| ------------------------------------ | --------------------------------------------- | -------- | --------------------------- |
| Эпизодическая/семантическая модель   | Разделение событий и фактов                   | Средняя  | Частично (Memory Center)    |
| Гибраидный поиск (BM25 + embeddings) | Быстро и по смыслу                            | Низкая   | Есть (Orama + Transformers) |
| RAG                                  | Подстановка релевантных фрагментов в контекст | Низкая   | Есть                        |
| Консолидация + забывание             | Сжатие похожего, затухание веса               | Высокая  | Нет                         |
| Двойное время фактов                 | valid_from/to vs recorded_at                  | Высокая  | Нет                         |
| Знаниевый граф/Junction              | Связи между источниками                       | Высокая  | Есть (Crystal + Junction)   |
| Blackboard/Global Workspace          | Общий «фокус внимания»                        | Высокая  | Нет                         |
| Память как контекст с TTL/бюджетом   | Ограничение объёма                            | Средняя  | Частично                    |
| Процедурная память (навыки)          | Повторяемые процедуры                         | Высокая  | Нет                         |
| Cross-session memory                 | Перенос знаний между сессиями                 | Средняя  | Частично                    |

## 3. Что в SuperAgents OS уже есть (не дублировать)

- Memory Center: единая карта памяти, граф, поиск по источникам, health/gaps.
- Гибраидный поиск BM25 + семантика (Orama + Transformers.js).
- Crystal Vault (факты с доказательствами), Junction (пересечения), Synthesis.
- Память сессий, когнитивные трассы, Wiki-Brain.

## 4. Что стоит добавить (редкое, не дублирующее)

| Приоритет | Паттерн                     | Зачем                                       | Объём   | Риск    |
| --------- | --------------------------- | ------------------------------------------- | ------- | ------- |
| Высокий   | Консолидация + забывание    | Не дать памяти «засориться», искать быстрее | Большой | Средний |
| Высокий   | Процедурная память (навыки) | Система учится процедурам                   | Большой | Средний |
| Средний   | Двойное время фактов        | Отличать «устарело» от «было ложным»        | Средний | Низкий  |
| Средний   | Blackboard/Global Workspace | Общий фокус внимания                        | Большой | Высокий |
| Низкий    | Проспективная память        | Напоминания «по контексту»                  | Средний | Низкий  |

## 5. Вывод

База памяти в SuperAgents OS уже сильно (Memory Center, гибраидный поиск, Crystal Vault). Самые редкие и ценные добавления — **консолидация+забывание** и **процедурная память (навыки)**; за ними — **двойное время фактов** и **blackboard**.
