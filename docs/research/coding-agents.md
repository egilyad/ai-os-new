# Исследование: кодинг-агенты

> Тема: как устроены агенты, которые пишут/правят код (Codex, Claude Code, Aider, OpenHands и др.). Какие паттерны стоит перенять в SuperAgents OS, не дублируя существующее.

## 1. Классы кодинг-агентов

| Тип                     | Суть                                | Примеры                    |
| ----------------------- | ----------------------------------- | -------------------------- |
| Редактор-агент          | Правки в репозитории с проверкой    | Codex, Claude Code, Aider  |
| Виртуальный инженер     | Полный цикл: план → правки → тесты  | OpenHands, Devin-подобные  |
| Интерактивный ассистент | Диалог + код                        | GitHub Copilot, Cursor     |
| Автономный флот         | Несколько агентов над большим кодом | Специализированные системы |

## 2. Ключевые паттерны

| Паттерн                  | Суть                           | Редкость | Статус у нас          |
| ------------------------ | ------------------------------ | -------- | --------------------- |
| Sub-agent spawn          | Дочерние агенты с контекстом   | Высокая  | Нет                   |
| Песочница / изоляция     | Безопасное выполнение кода     | Средняя  | Нет (BLOCKED-RUNTIME) |
| Test-driven loop         | Сначала тест, потом код        | Средняя  | Частично              |
| Файловые разрешения      | Подтверждение на запись/чтение | Средняя  | Частично              |
| Git-интеграция           | Диффы, ветки, PR               | Низкая   | Частично              |
| Итеративная самопроверка | Запуск тестов, фикс ошибок     | Средняя  | Частично              |
| Семантическая навигация  | Поиск по символиам/коду        | Средняя  | Частично              |

## 3. Что в SuperAgents OS уже есть (не дублировать)

- Кодинг-инструменты, терминал, workspace, проекты, задачи.
- Aider/Codex-подобные адаптеры (в rivals), компьютер-use задел.
- Автономия, планировщик, конфиг-ревизии.

## 4. Что стоит добавить (редкое, не дублирующее)

| Приоритет | Паттерн            | Зачем                 | Объём   | Риск    |
| --------- | ------------------ | --------------------- | ------- | ------- |
| Высокий   | Test-driven loop   | Надёжность правок     | Средний | Низкий  |
| Высокий   | Песочница/изоляция | Безопасное выполнение | Средний | Средний |
| Средний   | Sub-agent spawn    | Параллельные правки   | Средний | Средний |
| Средний   | Git-дифф/эп        | Контроль изменений    | Средний | Низкий  |

## 5. Вывод

У нас есть инструменты и задел, но не хватает замкнутого цикла «план → правка → тест → фикс». Главные добавления — **test-driven loop** и **песочница**; затем sub-agent spawn и git-диффы.
