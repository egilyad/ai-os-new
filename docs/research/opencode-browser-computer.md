# Управление компьютером и браузером с помощью opencode

> Статья: как использовать opencode (AI-кодинг агент для терминала) для управления браузером и компьютером: навигация, извлечение данных, автоматизация и безопасность.

## 1. Что такое opencode

**opencode** — открытый AI-кодинг агент для терминала (также есть настольное приложение и IDE-расширение). Он умеет работать с кодом, запускать команды, читать/писать файлы, искать по проекту, обращаться к вебу и подключать внешние инструменты через **MCP** (Model Context Protocol).

## 2. Встроенные инструменты, полезные для веба и компьютера

| Инструмент                | Что делает                       | Для чего                        |
| ------------------------- | -------------------------------- | ------------------------------- |
| `bash`                    | Выполняет команды оболочки       | Управление компьютером, скрипты |
| `webfetch`                | Получает содержимое страницы     | Чтение URL                      |
| `websearch`               | Поиск по вебу (Exa/Parallel)     | Поиск информации                |
| `read` / `write` / `edit` | Чтение/запись файлов             | Работа с файлами                |
| `skill`                   | Загружает Agent Skill (SKILL.md) | Повторяемые процедуры           |
| `todowrite`               | Ведёт список задач               | Многошаговые задачи             |
| `question`                | Спрашивает пользователя          | Подтверждение/уточнение         |

## 3. Управление браузером

### 3.1. Чтение страниц (просто)

- `webfetch` — получить содержимое URL прямо в диалоге.
- `websearch` — найти информацию.
  Этого достаточно для «почтения» веба. Но для действий (клики, формы) нужен браузерный движок.

### 3.2. Полноценное управление через MCP (Playwright)

Подключите **Playwright MCP** сервер. Это даёт opencode инструменты для реального управления браузером: навигация, клики, заполнение форм, скриншоты.

В `opencode.json` (или `opencode.jsonc`):

```jsonc
{
  "mcp": {
    "playwright": {
      "type": "local",
      "command": ["npx", "-y", "@playwright/mcp"],
      "enabled": true,
    },
  },
}
```

После этого в промптах можно просить opencode «открой страницу, заполни форму, сделай скриншот» — инструменты Playwright станут доступны агенту.

Пример промпта:

```
use the playwright tools to open https://example.com, fill the search field with "opencode", and take a screenshot.
```

### 3.3. Другие MCP-серверы для веба

- **Playwright/MCP** — браузерная автоматизация.
- **Firecrawl / Jina** (по желанию) — скрейпинг и извлечение структурированных данных.
- MCP-серверы расширяют opencode внешними инструментами (remote/local).

## 4. Управление компьютером

### 4.1. Через `bash`

- opencode выполняет команды оболочки: запуск приложений, работа с файлами, скрипты.
- Пример: «открой файл X, запусти тесты, покажи результат».
- На Windows рекомендуется WSL для полной совместимости.

### 4.2. Скриншоты и автоматизация GUI

- Через `bash` можно вызывать утилиты скриншотов и автоматизации.
- Через MCP/custom tools можно добавить управление GUI (клики по координатам, работа с окнами).
- Эти действия — то же, что «Computer Use», но реализуемое через команды/инструменты.

### 4.3. Custom Tools

В `opencode.json` можно определить свои функции, которые агент сможет вызывать. Это удобно для привязки к своим скриптам/API.

## 5. Безопасность

- **Permissions**: контролируйте, какие инструменты разрешены, запрещены или требуют одобрения.

```jsonc
{
  "permission": {
    "edit": "allow",
    "bash": "ask",
    "webfetch": "allow",
    "playwright_*": "ask",
  },
}
```

- Для опасных действий (bash, запись, MCP-инструменты) ставьте `"ask"` — opencode будет запрашивать подтверждение.
- Будьте осторожны с инструментами, которые могут отправлять данные или менять систему.

## 6. Практические сценарии

| Сценарий                         | Как                                      |
| -------------------------------- | ---------------------------------------- |
| Прочитать документацию           | `webfetch https://...`                   |
| Найти актуальную информацию      | `websearch ...`                          |
| Пройти по сайту и собрать данные | Playwright MCP + извлечение текста       |
| Автоматизировать повторяемое     | Agent Skill (SKILL.md) + custom commands |
| Проверить приложение/браузер     | Playwright (скриншоты, клики, формы)     |
| Работа с файлами/компьютером     | `bash` + `read`/`write`/`edit`           |

## 7. Итог

opencode — мощный фундамент для управления браузером и компьютером:

- **Простые задачи**: `webfetch` + `websearch`.
- **Полноценный браузер**: Playwright MCP-сервер.
- **Компьютер/файлы**: `bash` + `read`/`write`/`edit` + custom tools.
- **Безопасность**: permissions (`allow`/`deny`/`ask`).
- **Повторяемость**: Agent Skills и custom commands.

Для «настоящего» компьютерного управления (произвольный GUI) потребуется добавить MCP/custom tools под свои нужды (скриншоты, координаты, эмуляция ввода) — это расширяется поверх opencode.
