# Исследование: безопасность (минимум)

> Краткое закрытие темы «для приличия». Глубокое погружение не требуется — только самые критичные пункты.

## Минимальный обязательный минимум

| Пункт                                | Что                            | Статус у нас              |
| ------------------------------------ | ------------------------------ | ------------------------- |
| Шифрование ключей at-rest (KeyVault) | Ключи не лежат plaintext       | Написан, не подключён     |
| Маскировка секретов в логах/экспорте | Секреты не утекают             | Частично (есть sanitize)  |
| Песочница для кода                   | Изоляция выполнения            | Нет                       |
| Валидация URL/SSRF                   | Защита от подмены URL          | Частично (есть httpGuard) |
| Агент-щит / разрешения               | Подтверждение опасных действий | Частично                  |

## Вывод

Критичный минимум — **подключить KeyVault** и **довести маскировку**; остальное (песочница, SSRF) уже частично закрыто или в планах.
