# Исследование (сессия 5): интеграция управления браузером/компьютером в SuperAgents OS

> Финальный синтез пяти сессий: итоговая архитектура BrowserHarness, UX, связка с памятью/Crystal/Deep Research и финальные решения.

## 1. Итоговая архитектура

```
┌─ UI (существующие панели) ────────────────────────────┐
│ Research Cockpit · Graph Workbench · Агенты · Settings │
├─ BrowserHarness (новый сервис) ──────────────────────┤
│ · Playwright-движок (абстракция под движок)           │
│ · Гибрид управления: DOM/accessibility → vision → xy  │
│ · Гибрид безопасности: сеть, разрешения, аудит        │
│ · Устойчивость: retry/timeout/fallback/восстановление │
├─ Knowledge/Memory интеграция ────────────────────────┤
│ Извлечение данных со страниц → Crystal Vault/память   │
├─ Deep Research интеграция ───────────────────────────┤
│ Сбор источников для исследований (скрейпинг)          │
└─ Наблюдаемость ──────────────────────────────────────┘
│ Скриншоты, трассы, replay, экспорт                    │
```

## 2. Ключевые компоненты

| Компонент                   | Назначение                            | Источник сессии |
| --------------------------- | ------------------------------------- | --------------- |
| BrowserHarness (Playwright) | Управление страницами                 | С1              |
| Гибрид управления           | DOM → vision → координаты             | С2              |
| ComputerUseAgent            | Произвольный GUI                      | С3              |
| SecurityGuard               | Сеть, разрешения, аудит               | С4              |
| ReliabilityLayer            | retry/timeout/fallback/восстановление | С4              |
| DataExtractor               | Контент → crystal/claims              | С1/С2           |

## 3. Связка с памятью/знаниями

- **DataExtractor** извлекает данные с веб-страниц.
- Извлечённое → **Crystal Vault** (факты с доказательствами/URL).
- Связь с **гибраидным поиском**: новые источники индексируются.
- Результаты доступны в Research Cockpit и дебатах.

## 4. Связка с Deep Research

- BrowserHarness как источник источников: агент «читает» страницы (не только поиск).
- Скрейпинг для глубоких исследований: сбор цитат, фактов, таблиц.
- Всё проходит через claim-centric evidence (проверка цитат).

## 5. UX

- Панель «Браузерные сессии»: список активных сессий, статус, скриншоты.
- Просмотр действий (шагов) с отменой.
- Привязка к Research Cockpit (переход к «браузерному агенту»).

## 6. Финальные решения по Roadmap

| Решение                                 | Соответствует фазе |
| --------------------------------------- | ------------------ |
| Использовать Playwright как движок      | Фаза 0             |
| Гибрид управления (DOM→vision→xy)       | Фаза 0/1           |
| Безопасность: сеть + разрешения + аудит | Фаза 1             |
| ComputerUseAgent для произвольного GUI  | Фаза 2             |
| DataExtractor → Crystal Vault           | Фаза 1             |
| Интеграция с Deep Research              | Фаза 3             |

## 7. Вывод

Управление браузером/компьютером интегрируется как **BrowserHarness**-сервис: Playwright + гибрид управления + безопасность + устойчивость, с выходом на Crystal Vault и Deep Research. Это реализуемо поэтапно (фазы 0–3 из Roadmap).
