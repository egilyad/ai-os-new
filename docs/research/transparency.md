# Исследование: прозрачность системы

> Тема: как сделать ИИ-ОС прозрачной для пользователя (почему такой ответ, происхождение данных, индикаторы доверия, наблюдаемость, аудит). Что усилить в SuperAgents OS.

## 1. Зачем прозрачность

Пользователь должен понимать, **почему** система выдала тот или иной результат, откуда взяты данные и насколько им можно доверять. Это ключ к доверию и к отладке.

## 2. Ключевые паттерны

| Паттерн                         | Суть                               | Редкость | Статус у нас                 |
| ------------------------------- | ---------------------------------- | -------- | ---------------------------- |
| «Почему такой ответ»            | Показать источники/роутинг/правила | Высокая  | Частично (чат, исследование) |
| Provenance/происхождение данных | Откуда каждая часть                | Высокая  | Частично (provenance)        |
| Индикаторы доверия              | Trust-скор источников/агентов      | Средняя  | Частично                     |
| Наблюдаемость (logs/traces)     | Полный след выполнения             | Средняя  | Есть                         |
| Аудит действий                  | Журнал чувствительных операций     | Средняя  | Частично                     |
| Визуализация процессов          | Графы/таймлайны                    | Средняя  | Есть (Graph Workbench)       |
| Открытая политика               | Показать применённые правила/вето  | Средняя  | Частично                     |
| Калибровка уверенности          | Честные проценты                   | Высокая  | Есть (Calibration)           |

## 3. Что в SuperAgents OS уже есть (не дублировать)

- Graph Workbench (9 линз), «Почему такой ответ» в чате.
- Responseance, trust-скор, аудит-журналы.
- Каскабровка уверенности (reliability diagram).
- Логи/трассы, EventBus.

## 4. Что стоит добавить (редкое, не дублирующее)

| Приоритет | Паттерн                                    | Зачем                         | Объём   | Риск   |
| --------- | ------------------------------------------ | ----------------------------- | ------- | ------ |
| Высокий   | «Почему такой ответ» для исследования      | Доверие к выводам             | Средний | Низкий |
| Высокий   | Индикаторы доверия в UI                    | Пользователь видит надёжность | Средний | Низкий |
| Средний   | Открытая политика (применённые вето/линзы) | Понятность                    | Средний | Низкий |
| Средний   | Аудит-дашборд                              | Полный журнал                 | Средний | Низкий |

## 5. Вывод

Прозрачность у нас уже неплохая (Graph Workbench, provenance, калибровка). Главные добавления — **индикаторы доверия в UI** и **полный «почему такой ответ» для исследования/выводов**.
