# Исследование: когнитивные компоненты для ИИ-ОС

> Тема: какие когнитивные компоненты усиливают ИИ-ОС (контроль мышления, внимание, обучение, модели мира/себя/пользователя, цели и время). Что усилить в SuperAgents OS, не дублируя существующее.

## 1. Что такое когнитивный компонент

Это «связующий слой» между знанием и рассуждением: что решает, на что смотреть, сколько думать, когда остановиться и что из опыта сделать навыком.

## 2. Ключевые компоненты

| Компонент                                          | Суть                                                          | Редкость | Статус у нас |
| -------------------------------------------------- | ------------------------------------------------------------- | -------- | ------------ |
| Метакогнитивный контроллер                         | Решает «сколько думать» (прямой ответ / дебат / исследование) | Высокая  | Нет          |
| Глобальное рабочее пространство (Global Workspace) | Общий «фокус внимания»                                        | Высокая  | Нет          |
| Рабочая память со слотами                          | Цель, подцели, факты, открытые вопросы                        | Высокая  | Нет          |
| Детектор новизны/неожиданности                     | Ошибка предсказания                                           | Высокая  | Нет          |
| Процедурная память (навыки)                        | Удачные цепочки → навыки                                      | Высокая  | Нет          |
| Само-рефлексия (Reflexion)                         | Разбор после задачи                                           | Высокая  | Нет          |
| Модель пользователя                                | Уровень, цели, стиль                                          | Средняя  | Нет          |
| Модель себя (каталог возможностей)                 | Что система умеет/не умеет                                    | Средняя  | Нет          |
| Менеджер целей                                     | Долгие цели и прогресс                                        | Средняя  | Нет          |
| Проспективная память                               | «Помнить, что сделать позже»                                  | Средняя  | Нет          |

## 3. Что в SuperAgents OS уже есть (не дублировать)

- Когнитивные трассы и CognitiveService (но makeDecision — стаб, всегда alts[0]).
- Линзы (перспективы анализа), исключения (вето).
- Цели персон (поведение ролей).
- Hypothesis/Knowledge Generator, дебаты, исследования.

## 4. Что стоит добавить (редкое, не дублирующее)

| Приоритет | Компонент                   | Зачем                      | Объём   | Риск    |
| --------- | --------------------------- | -------------------------- | ------- | ------- |
| Высокий   | Само-рефлексия (Reflexion)  | Учиться на задачах         | Средний | Средний |
| Высокий   | Модель пользователя         | Адаптация ответов          | Средний | Средний |
| Средний   | Метакогнитивный контроллер  | Разумный выбор глубины     | Большой | Высокий |
| Средний   | Детектор новизны            | Обращать внимание на новое | Средний | Средний |
| Средний   | Процедурная память (навыки) | Повторяемые процедуры      | Большой | Средний |
| Низкий    | Global Workspace            | Общий фокус                | Большой | Высокий |

## 5. Вывод

Самые доступные и ценные добавления — **само-рефлексия** и **модель пользователя**. Контроллер глубины и Global Workspace — крупные и рискованные, их стоит отложить. Заодно починить **CognitiveService.makeDecision** (сейчас стаб).
