# Исследование: ошибки в мультиагентных системах и борьба с ними

> Тема: типы ошибок в мультиагентных ИИ-ОС, компоненты устойчивости, агенты-аудиторы, быстрый поиск и ремонт. Цель — выяснить и внедрить технологии для сопротивления ошибкам.

## 1. Типы ошибок

| Класс            | Примеры                                               | Где возникает        |
| ---------------- | ----------------------------------------------------- | -------------------- |
| Модельные        | Галлюцинации, деградация вывода                       | LLM-вызовы           |
| Оркестрационные  | Зависшие задачи, гонки, конфликты агентов             | Планировщик/EventBus |
| Инструментные    | Падение инструмента, недоступный API, неверный формат | Tool-вызовы          |
| Состояние        | Несогласованность БД, частичные записи                | Память/IndexedDB     |
| Инфраструктурные | Сеть, таймауты, перегрузка                            | Адаптеры/провайдеры  |

## 2. Паттерны устойчивости

| Паттерн           | Суть                             | Редкость | Статус у нас |
| ----------------- | -------------------------------- | -------- | ------------ |
| Circuit breaker   | Отключение сбоящего провайдера   | Низкая   | Есть         |
| Retry с backoff   | Повтор с паузами                 | Низкая   | Есть         |
| Fallback-цепочка  | Запасные провайдеры              | Низкая   | Есть         |
| Watchdog/таймауты | Зависшие задачи                  | Средняя  | Частично     |
| Идемпотентность   | Повторные операции безопасны     | Средняя  | Частично     |
| Транзакции/откат  | Атомарные изменения              | Средняя  | Частично     |
| Self-healing      | Автовосстановление состояния     | Высокая  | Нет          |
| Агент-аудитор     | Проверка действий другого агента | Высокая  | Нет          |

## 3. Агенты-аудиторы и быстрый поиск/ремонт

| Паттерн            | Суть                                 | Редкость | Статус у нас           |
| ------------------ | ------------------------------------ | -------- | ---------------------- |
| Аудит-агент        | Независимо проверяет действия/выводы | Высокая  | Нет                    |
| Диагностика/трассы | Быстрый поиск причины                | Средняя  | Частично (logs/traces) |
| Авто-ремонт        | Генерация фикса + применение         | Высокая  | Нет                    |
| Роллбек            | Откат к хорошему состоянию           | Средняя  | Частично (snapshots)   |
| Метрики/алерты     | Раннее обнаружение                   | Средняя  | Частично               |
| Дегубаггер-агент   | Находит и объясняет баг              | Высокая  | Нет                    |

## 4. Что в SuperAgents OS уже есть (не дублировать)

- Декораторы: circuit breaker, retry, rate-limit, fallback, cost, cache.
- EventBus, логи/трассы, диагностика, snapshot/time-machine (частично).
- Аудит-журналы, trust-скор, governor (ранняя остановка).
- Research Engine с обработкой ошибок об.

## 5. Что стоит добавить (редкое, не дублирующее)

| Приоритет | Паттерн                           | Зачем                        | Объём   | Риск    |
| --------- | --------------------------------- | ---------------------------- | ------- | ------- |
| Высокий   | Агент-аудитор                     | Проверка выводов/действий    | Средний | Средний |
| Высокий   | Self-healing + автовосстановление | Меньше ручного вмешательства | Средний | Средний |
| Средний   | Авто-ремонт + роллбек             | Быстрое исправление          | Средний | Средний |
| Средний   | Дегубаггер-агент                  | Находит и объясняет баг      | Средний | Средний |
| Средний   | Watchdog для зависших задач       | Надёжность                   | Средний | Средний |

## 6. Вывод

Фундамент устойчивости у нас есть (декораторы, traces, snapshots). Самые ценные добавления — **агент-аудитор**, **self-healing/автовосстановление** и **авто-ремонт с роллбеком**. Это превратит систему из «детектирует сбои» в «сама сопротивляется и чинит».
