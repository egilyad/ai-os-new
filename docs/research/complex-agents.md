# Исследование: сложные агенты

> Тема: архитектура «сложных» агентов (роли, планирование, инструменты, память, само-организация, иерархия). Что усилить в SuperAgents OS, не дублируя существующее.

## 1. Что делает агента «сложным»

- Многошаговое планирование и пере-планирование.
- Использование инструментов/памяти/знаний.
- Ролевая специализация и иерархия.
- Способность вызывать субагентов.
- Рефлексия и обучение на опыте.
- Отказоустойчивость (retry, fallback, бюджеты).

## 2. Ключевые паттерны

| Паттерн                             | Суть                                         | Редкость | Статус у нас           |
| ----------------------------------- | -------------------------------------------- | -------- | ---------------------- |
| Ролевые команды (Crew/Team)         | Совместная работа специализированных агентов | Средняя  | Есть (Crew, Council)   |
| Иерархия агентов (родитель/потомок) | Делегирование                                | Высокая  | Частично               |
| Sub-agent spawn с бюджетом          | Дочерние агенты                              | Высокая  | Нет                    |
| ReAct / планирование-действие       | Чередование рассуждения и действий           | Низкая   | Есть                   |
| Само-рефлексия (Reflexion)          | Уроки после задач                            | Высокая  | Нет                    |
| Человек-в-цикле                     | Подтверждение опасных шагов                  | Средняя  | Частично               |
| Песочница для действий              | Безопасное выполнение                        | Средняя  | Нет                    |
| Долговременная память агента        | Накапливание опыта                           | Средняя  | Частично (agentMemory) |

## 3. Что в SuperAgents OS уже есть (не дублировать)

- Роли, спавн из шаблонов, скиллы, топология.
- Crew (команды), Council (советы), Director, комнаты.
- agentMemory, журнал выполнений, конфиг-ревизии.
- Планировщик, автономия.

## 4. Что стоит добавить (редкое, не дублирующее)

| Приоритет | Паттерн                     | Зачем                        | Объём   | Риск    |
| --------- | --------------------------- | ---------------------------- | ------- | ------- |
| Высокий   | Sub-agent spawn с изоляцией | Глубина и параллелизм        | Средний | Средний |
| Высокий   | Само-рефлексия              | Обучение на опыте            | Средний | Средний |
| Средний   | Иерархия с делегированием   | Управление сложными задачами | Средний | Средний |
| Средний   | Песочница действий          | Безопасность                 | Средний | Средний |

## 5. Вывод

База агентов у нас уже широкая (роли, Crew, Council, agentMemory). Главные добавления — **sub-agent spawn с изоляцией** и **само-рефлексия**, затем иерархия и песочница.
