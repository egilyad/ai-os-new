# Исследование: управление браузером и компьютером ИИ

> Тема: как агенты управляют браузером и ОС (GUI-агенты, computer-use, браузерная автоматизация). Что усилить в SuperAgents OS, не дублируя существующее.

## 1. Классы подходов

| Подход                 | Суть                                               | Примеры                              |
| ---------------------- | -------------------------------------------------- | ------------------------------------ |
| Browser automation API | DOM/CDP/Playwright — программное управление        | Playwright, Puppeteer                |
| GUI/Computer Use       | «Зрение + клики» по экрану (скриншоты, координаты) | Claude Computer Use, OpenAI Operator |
| Гибраидный             | Сочетание DOM-разбора и визуального                | Современные агенты                   |
| Web-agent-специфичный  | Навигация, формы, поиск, извлечение                | WebVoyager-подобные                  |

## 2. Ключевые паттерны

| Паттерн                         | Суть                         | Редкость | Статус у нас          |
| ------------------------------- | ---------------------------- | -------- | --------------------- |
| Браузерный харнесс (Playwright) | Автоматизация страниц        | Низкая   | Нет (BLOCKED-RUNTIME) |
| Computer Use (зрение+клики)     | Управление любым GUI         | Средняя  | Нет                   |
| Агент-щит / безопасность        | Ограничение опасных действий | Средняя  | Нет                   |
| Скриншот-пайплайн               | Обработка скриншотов в граф  | Средняя  | Нет                   |
| Memory/состояние страницы       | Сохранение контекста вкладки | Средняя  | Нет                   |
| Человек-в-цикле                 | Подтверждение действий       | Средняя  | Частично              |

## 3. Что в SuperAgents OS уже есть (не дублировать)

- Проект «Computer/Browser Use» уже заявлен (см. вики-статью computer-browser-use).
- Инструменты: Webhook, MCP, коннекторы, частично browser-harness (BLOCKED-RUNTIME: реальный браузер не подключён).
- Песочница для кода — в планах (BLOCKED-RUNTIME).

## 4. Что стоит добавить (редкое, не дублирующее)

| Приоритет | Паттерн                                         | Зачем                             | Объём   | Риск    |
| --------- | ----------------------------------------------- | --------------------------------- | ------- | ------- |
| Высокий   | Браузерный харнесс (Playwright) с безопасностью | Полноценное управление страницами | Средний | Средний |
| Средний   | Computer Use (зрение+клики)                     | Управление любым GUI              | Большой | Высокий |
| Средний   | Скриншот-пайплайн                               | Визуальный анализ страниц         | Средний | Средний |
| Высокий   | Агент-щит/безопасность действий                 | Защита от опасных последствий     | Средний | Средний |

## 5. Вывод

У нас есть задел (computer-browser-use, инструменты), но главное — **подключить реальный браузерный харнесс** (Playwright) и **агент-щит** для безопасности действий. Computer Use (зрение+клики) — следующий уровень, но крупный и дорогой.
