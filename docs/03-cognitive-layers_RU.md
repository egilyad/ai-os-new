# 03 — Когнитивные слои

## Слой концепций

Система реализует **5-слойный когнитивный стек**, который преобразует неструктурированный текст LLM в структурированные, измеримые артефакты рассуждения. Каждый слой имеет свою ответственность — генерация создаёт текст, управление структурирует взаимодействие, разнообразие предотвращает групповое мышление, измерение количественно оценивает качество, а интерпретация извлекает смысл.

Эта многослойная архитектура является основным исследовательским вкладом системы: она делает многоагентные рассуждения **проверяемыми, сравнимыми и улучшаемыми**.

## Слой поведения

### Слой 1 — Генерация

Формирует промпты LLM со структурным контекстом (роль, ограничения, тон температуры, состояние дебатов, родительские ссылки). Вызывает LLM с до 3 повторами через 3 уровня резервирования. Возвращает структурированный `DebateArgument` с оценкой уверенности.

### Слой 2 — Управление (Управляющий)

После каждого аргумента извлекает утверждения, добавляет их в граф утверждений, проверяет на противоречия с существующими утверждениями, вычисляет оценку конвергенции. Определяет, следует ли остановить дебаты, на основе новизны, конвергенции и разрешения противоречий.

### Слой 3 — Разнообразие

Отслеживает, какие выступающие внесли вклад, какие позиции они заняли и соблюдаются ли ограничения. Предотвращает доминирование одного выступающего. Для стратегии `constrained` проверяет соблюдение с помощью эвристических шаблонов.

### Слой 4 — Измерение

Вычисляется при остановке дебатов:

- **Метрики графа**: статистика структуры дерева (глубина, ветвление, доля сирот)
- **Метрики активности**: участие по агентам (количество, слова, уверенность, ответы)
- **Метрики качества**: глубина (лексическое разнообразие, широта тем), оригинальность (само-/перекрёстные повторения через Jaccard), полезность (релевантность, наличие доказательств, структура)

### Слой 5 — Интерпретация

Чистое вычисление (без LLM) на основе артефактов дебатов:

- **Сводка**: однострочное количественное описание
- **Пик разногласий**: раунд и интенсивность максимального расхождения
- **Изменяющие траекторию аргументы**: аргументы, которые изменили фокус, углубили, опровергли или сдвинули консенсус
- **Корреляция ограничений**: для стратегии `constrained`, как каждое ограничение повлияло на глубину и уверенность
- **Инсайты**: эвристические выводы (уровень конвергенции, баланс, равенство участия)

Слои **строго упорядочены** — каждый зависит от выхода нижележащего слоя. Генерация питает управление, управление питает разнообразие, разнообразие питает измерение, измерение питает интерпретацию.
