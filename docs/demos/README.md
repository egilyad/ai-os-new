# Демонстрации SuperAgents OS

Пять приоритетных сценариев со скриншотами реального интерфейса. Изображения
снимает Playwright с собранного приложения — это не макеты.

- Версия приложения на момент снимков: **4.5.0** (`package.json`)
- Дата снимков: 2026-10-17
- Генерация: `npm run build && npm run gen:demos` (пишет `docs/demos/img/*.png`)
- Определяющий код: `e2e/screenshots.spec.ts`

| Демонстрация | Маршрут | Что показывает |
| --- | --- | --- |
| [Чат с ИИ](./chat.md) | `/chat` | диалог с провайдером, стриминг, режимы |
| [Дебаты агентов](./debate.md) | `/debate` | роли, стратегии, раунды |
| [Провайдеры и ключи](./providers.md) | `/keys` | ключи, health, модели |
| [Память](./memory.md) | `/memory` | записи, поиск, граф связей |
| [Диагностика](./diagnostics.md) | `/diagnostics` | здоровье системы, трейсы, алерты |

Скриншоты отражают чистый профиль (один тестовый ключ, без истории), поэтому
экраны показывают честные пустые состояния, а не выдуманные данные.

Портал документации: <https://egilyad.github.io/ai-os-new/wiki/>
