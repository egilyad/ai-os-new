# 🔵 REFERENCE — справочники, контракты, описания

Нормативные документы и справочники: контракты, реестры, матрицы, каталоги событий.
Могут быть источником истины для кода (Normative).

## Правила

- Реестры (`ПОЛНЫЙ_РЕЕСТР.md`, `SERVICES_*.md`) — только машинно-проверяемые или помеченные датой подсчёта.
- Дублирующиеся реестры — один остаётся здесь, остальные → `../superseded/`.
- Устаревшие цифры без даты → сначала датировать, потом решать.

## Состав

Заполняется по мере триажа (кандидаты: `CAPABILITY_MATRIX.md`, `events.md`, `SERVICES_RU.md`, один UI-реестр, один реестр сервисов).
