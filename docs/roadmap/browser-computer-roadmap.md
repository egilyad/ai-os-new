# Roadmap: управление браузером и компьютером (browser/computer use)

> Отдельный roadmap по теме управления браузером и компьютером ИИ — «по максимуму». Полное погружение, даже если это большая работа.
> Исследование по этой теме будет вестись отдельно (5+ сессий) и уточнит детали.

## 1. Цель

Дать агентам SuperAgents OS возможность реально управлять браузером и компьютером: открывать сайты, заполнять формы, извлекать данные, работать с приложениями и файлами — безопасно и наблюдаемо.

## 2. Общая архитектура (слои)

```
┌─ Пользовательский слой ─────────────────────────────┐
│ UI: панель управления (сессии, скриншоты, разрешения)│
├─ Оркестрация (Agent Layer) ───────────────────────┤
│ Агент-планировщик → субагенты → guardrails/аудит   │
├─ Действия (Action Layer) ─────────────────────────┤
│ BrowserHarness (Playwright) · ComputerUse (GUI)    │
├─ Изоляция и безопасность (Sandbox Layer) ─────────┤
│ Песочница, сеть-политика, разрешения, аудит        │
├─ Наблюдаемость (Observability) ───────────────────┤
│ Скриншоты, DOM-слепки, логи, трассы, replays       │
└─ Хранилище / состояние ───────────────────────────┘
│ Сессии, скриншоты, результаты, артефакты           │
```

## 3. Компоненты (что строить)

| Компонент                            | Назначение                                          | Приоритет |
| ------------------------------------ | --------------------------------------------------- | --------- |
| BrowserHarness (Playwright)          | Управление страницами: навигация, DOM, формы, клики | P0        |
| Обработка скриншотов                 | Захват экрана → изображение → анализ                | P1        |
| Computer Use (зрение+клики)          | Управление произвольным GUI                         | P2        |
| Агент-планировщик действий           | Разбиение цели на шаги в браузере                   | P0        |
| Guardrails/безопасность              | Разрешения, блокировка опасных действий             | P0        |
| Песочница сессии                     | Изоляция браузера/приложений                        | P1        |
| Аудит и трассы                       | Полный след действий + replay                       | P1        |
| Наблюдаемость/UX                     | Панель управления, статусы, скриншоты               | P1        |
| Извлечение данных и структурирование | Контент страниц → данные (claim/evidence)           | P1        |

## 4. Этапы внедрения

### Фаза 0 — фундамент (P0)

- BrowserHarness на Playwright (навигация, клики, ввод, извлечение DOM).
- Агент-планировщик действий над браузером.
- Guardrails: разрешения на действия, deny-list опасных URL/действий.
- Минимальная панель управления + просмотр скриншотов.

### Фаза 1 — безопасность и наблюдаемость (P1)

- Песочница сессии (изоляция, сеть-политика).
- Скриншоты + анализ изображений (vision-модель).
- Аудит: трассы действий, replay, экспорт.
- Извлечение данных со страниц → crystal/claims (связка с Memory/Crystal Vault).
- UX: панель управления браузерными сессиями.

### Фаза 2 — компьютерное управление (P2)

- Computer Use: «зрение + клики» по экрану для произвольного GUI.
- Виртуальный рабочий стол / изоляция приложений.
- Работа с файлами и офисными приложениями.
- Гибрид: DOM + визуальное управление.

### Фаза 3 — расширение (P3)

- Автономные сценарии: e2e-тесты, веб-скрейпинг, заполнение форм.
- Интеграция с дебатами/исследованиями (сбор данных для Deep Research).
- Массовый параллельный запуск сессий (несколько экземпляров).

## 5. Безопасность (ключевое)

- **Сеть**: явная политика (куда можно ходить), блокировка metadata/локальной сети.
- **Действия**: подтверждение человека на деструктивные операции (отправка, покупка, загрузка).
- **Данные**: секреты/куки не попадают в логи; маскировка.
- **Изоляция**: песочница между сессиями.
- **Аудит**: каждый шаг записывается; возможность отката.

## 6. Наблюдаемость и UX

- Панель «браузерные сессии»: список активных сессий, статус, скриншоты.
- Просмотр «шагов» (цепочка действий) с возможностью отмены.
- Привязка к существующим панелям: Research Cockpit, Graph Workbench, агенты.

## 7. Оценка и метрики

- Успешность задачи в браузере (task success rate).
- Время до выполнения; число шагов.
- Безопасность: 0 несанкционированных действий; 0 утечек секретов.
- Наблюдаемость: 100% действий имеют трассу и replay.

## 8. Риски и митигация

- **Сложность Web-автоматизации**: нестабильные селекторы → использовать и DOM, и визуальные ориентиры.
- **Безопасность**: строгие песочница и разрешения.
- **Ресурсы**: скриншоты/vision дороги → кэширование, выборочный анализ.
- **Экосистема**: зависимость от Playwright/браузеров → абстракция за интерфейсом.

## 9. Связь с другими темами

- Память/знания: извлечённые данные → Crystal Vault.
- Deep Research: сбор данных для исследований.
- Устойчивость: retry/fallback для браузерных операций.
- Агенты: субагенты для параллельных браузерных задач.
