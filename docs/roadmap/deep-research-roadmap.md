## Порядок и измерение

- Выполнять строго P0 → P1 → P2 → P3.
- Метрики успеха:
  - Безопасность/устойчивость: 0 секретов в открытом виде; меньше зависших задач; аудитор находит реальные расхождения.
  - Глубина: рост уникальных источников на исследование; рост faithfulness.
  - Обучаемость: рост числа навыков и их успешности.
  - Скорость: метрики UI (без блокировок), время старта.
- Каждый пункт заканчивается коммитом + CI-прогоном.
