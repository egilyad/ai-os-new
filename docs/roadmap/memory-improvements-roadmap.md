# Roadmap улучшений «Память/Знания»

> **Источник:** аудит `docs/audits/memory-audit.md` (M1–M13).
> **Ветка:** `ai-os-new-fix-debate-text-truncation`.

---

## Принцип

Начать с локальных, безопасных правок (консолидация данных/флагов), затем — оптимизация поиска, затем — крупные архитектурные решения (единое векторное пространство).

## Sprint 1 (P0) — быстрые фиксы

| Задача | ID | Сложность |
|---|---|---|
| Консолидировать поле вектора в `metadata.vectorData` (убрать дублирование `vector`/`embedding`) | M6 | низкая |
| Заменить глобальный `providerEmbeddingsDisabled` на per-provider cooldown/retry | M5 | средняя |
| Реальный (или консервативный) подсчёт бюджета токенов WikiBrain | M13 | низкая |

## Sprint 2 (P1) — поиск и хранение

| Задача | ID | Сложность |
|---|---|---|
| Оптимизировать `searchAdvanced` (убрать подъём до 100 при limit=1) | M3 | средняя |
| Двухпространственный поиск (hash+provider) или явный выбор пространства | M4 | средняя |
| Индекс поверх `knowledgeSources` вместо линейного сканирования | M10 | средняя |
| Перенести `enforceLimit` и на БД / документировать поведение | M2 | средняя |

## Sprint 3 (P2) — архитектура

| Задача | ID | Сложность |
|---|---|---|
| Единое векторное пространство памяти + WikiBrain (или явный мост) | M9 | высокая |
| Свести две RAG-линии дебатов к одному источнику | M7 | высокая |
| Гибридный поиск для кросс-дебат-памяти (снять keyword-overlap) | M12 | средняя |
| Инъекция: enrich URL-ингest (пустой источник при сбое) | M11 | низкая |
