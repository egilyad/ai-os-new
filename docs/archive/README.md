# docs/archive — исторический материал

> Архив ≠ удаление. Сюда переносится то, что больше не описывает текущую ветку,
> но сохраняет ценность как baseline/история. Ничего из `archive/` не считается
> источником истины. Перед удалением чего-либо отсюда — `git grep` по имени файла.

## Статусы документов (правила)

| Статус | Значение |
|---|---|
| **Current** | Описывает код текущей ветки, имеет дату проверки |
| **Normative** | Контракт, которому должен соответствовать код |
| **Active plan** | Имеет владельца, статус и следующий шаг |
| **Historical** | Сохранено для контекста (этот каталог), не источник текущего состояния |
| **Scratch/dump** | Временный материал, кандидат на удаление после проверки |
