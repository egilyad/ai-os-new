# 13 — UI: where this agent renders

## AgentsPanel (VERIFIED)

Primary surface: `src/components/AgentsPanel/`. This agent appears in:

- `AgentsPanelView.tsx` — grid/list of all agents.
- `AgentCard.tsx` — renders one card. Calls `resolveAgentIdentity(agent.id)`
  (`AgentCard.tsx:23`) and shows `identity.avatar.emoji` (💡) + `color` (#10b981)
  (`AgentCard.tsx:56-63`), `agent.name`, `agent.role`, and specializations
  (`AgentCard.tsx:66-70`). Click → `onSelect` → detail.
- `AgentDetailPanel.tsx` / `AgentDetailPanelProps.ts` — full identity, stats,
  config, capabilities, history, handoffs, observability tabs.
- `AgentIdentityEditor.tsx` / `AgentWizard.tsx` — edit/spawn agents (doc-simplifier
  is editable like any node; its curated fields can be overridden).
- `AgentAvatar.tsx` — deterministic emoji/color; for this agent the node config
  already carries 💡/#10b981 so it is used directly.

## Identity rendering (VERIFIED)

`resolveAgentIdentity` (`agent-identity.ts:62`) is the single seam; the card shows
the curated display name "Maya Lindholm" via `identity.displayName`
(`agent-identity.ts:131`). NOTE: `AgentService.getAgents()` exposes the **label**
"Simplifier Agent" (`agent-service.ts:319`), while the _identity view_ shows
"Maya Lindholm". UI components that use `resolveAgentIdentity` show the display
name; raw `getAgents()` consumers show the label. Both refer to the same node id.

## RoomPanel (VERIFIED)

`RoomPanel` (`AGENTS.md` Step 6) lists `agentService.getAgents()` in a picker so a
human can invoke doc-simplifier (see `05_INVOCATION.md`). Shows the agent name in
the invocation card.

## Director / Debate UIs (VERIFIED)

- `DirectorPanel` (RunTab) lists scenario participants by id; if a scenario names
  `agent-doc-simplifier`, it appears there (`AGENTS.md` B5.4c).
- Debate participant pickers can include it (see `03_DEBATE.md`).

## Observability (VERIFIED)

Stats dashboards (`AgentStatsDashboard.tsx`, `LiveActivityStream.tsx`,
`EloLeaderboard.tsx`) read `AgentService.getStats('agent-doc-simplifier')`,
populated from `COGNITIVE_STEP_COMPLETED` (`02_AGENT_SERVICE.md`,
`07_COGNITIVE_EVENTS.md`).
