## Summary flags

- **EXISTS-BUT-UNUSED-as-feature (#11-13):** The three named specializations are pure prompt text. No dedicated Literature-Review / Synthesis / Citations service consumes them.
- **DEAD-for-this-agent (#15):** Lenses exist system-wide but are never attached to agent-research.
- **DEAD (#17):** `cognitive:decision:made` is emitted but has no consumer and is explicitly dropped by the event recorder.
- **POTENTIAL (#18-22):** Real, adjacent subsystems (Crystal, Synthesis, Generator, Research Engine, Workflows, scheduled invocation) could use this agent but currently do not.
- **PARTIAL/UNVERIFIED (#14):** `SEARCH_TOOLS` are declared; whether they resolve to a live web_search adapter for this node is not established by the topology/profile alone (INFERRED they are wired by the execution harness, but not guaranteed).
