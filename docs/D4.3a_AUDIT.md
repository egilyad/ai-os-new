## 3) Фактический путь `CouncilPanel → Facade.submitJudgeScore → canonical`

```
CouncilPanel (Fleet — Councils detail → Judge first judge → first participant)
  ↓ useCouncilStore / councilService.submitJudgeScore(sessionId, judgeId, winnerId, scores, rationale)
  ↓ ICouncilService (facade, same external API, no panel rewrite)
  ↓ CouncilServiceFacade.submitJudgeScore
    ├─ read oldSession weight = old.getSession(sessionId).judges.find(judgeId).weight ??1 (read-only, no write)
    ├─ weightedJudge.recordJudgeVote(sessionId, judgeId, winnerId, weight) — canonical WeightedJudgeEvaluator (implements IDebateEvaluator, not ICouncilJudgeEngine)
    ├─ return JudgeScore {judgeId, sessionId, winnerId, scores, blind: config.doubleBlind, createdAt}
    └─ NOT calling old.submitJudgeScore → old councilVotes kind:judge NOT written (old persistence NOT called) ✅
  ↓ DebateEngine (canonical) — judge vote in WeightedJudgeEvaluator votes Map (sessionId→judgeId→winnerId)
  ↓ CouncilServiceFacade.getSession(id) → old.getSession(id) base + merged evaluator.votes → scores[] (so UI sees canonical vote)
  ↓ DebateStore (via DebateEngine) — judge vote not yet in DebateStore row (still Map in-memory), but `getSession` merge makes CouncilPanel see it — **RUNTIME-PENDING** for Dexie persistence (no new table yet, per GO constraints)
  ↓ conclude (still old tally, will be D4.3c) — eventually `WeightedJudgeEvaluator.tallyWinner(sessionId)` + audience tie-break → winnerId → `DebateStore` canonical result
```

**Old path NOT called:** `council-service:308` `councilVotes.put kind:judge` + `scores.push 331` + `COUNCIL_JUDGED 313` **not executed** when `debateEngine` exists (facade early return). Old `council*` judge rows stay read-only for rollback.
