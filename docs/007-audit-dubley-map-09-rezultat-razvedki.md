# ADR-007: Аудит дублей (map-09): результат разведки

**Status**: Proposed
**Date**: 2026-11-17
**Deciders**: Sidekick (автогенерация из памяти)

## Context

Запись памяти #7 (Sidekick). Контекст решения — в разделе Decision; при необходимости расширить вручную.

## Decision

Пункт 5 плана улучшений ai-os-new: разведка дублей по docs/audits/waves/map-09-duplication.md завершена. Ключевые факты: (1) 19 папок rivals*/ (~550 КБ параллельного кода) — ВСЕ имеют внешние ссылки (rivals=189, rivals2=21, остальные 4-12), мёртвых копий нет, дедупликация = отдельная ветка/задача; (2) cache-service.ts и gemini-cache-service.ts — НЕ дубли (разные сервисы); (3) TechniquePanels (62 шт) и 97 setError-паттернов не трогаем (панели запрещены пользователем, набор diff большой). Решение: чистку rivals отложить в отдельную задачу, пункт 5 закрыт на этапе разведки БЕЗ изменений кода.
