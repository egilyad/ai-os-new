# Промпт: Computer Use (desk-mcp)

## Назначение

Шаблон для работы с настольными приложениями через Computer Use MCP
(desk-mcp): окна, скриншоты, клики, ввод текста, буфер обмена.

## Промпт

```
Выполни действие в настольном приложении с помощью Computer Use:

1. Найди окно: windows / active_window (уточни, какое приложение).
2. Сделай скриншот и прочитай экран (screenshot + ocr / read_screen).
3. Используй find / invoke / set_value / select для точных элементов.
4. Для кликов/ввода используй click / type / key (по координатам).
5. После каждого шага делай скриншот и проверяй результат.

Безопасность: не вводи пароли и секреты без явного подтверждения.
```

## Заметки

- Команда запуска: desk-mcp работает как MCP-сервер (см. opencode.jsonc).
