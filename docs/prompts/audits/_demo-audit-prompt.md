# Промпт: Аудит подсистемы

## Назначение

Шаблон для проведения аудита указанной подсистемы: состав, связи, риски,
дублирование, статус реализации и рекомендации.

## Промпт

```
Проведи аудит подсистемы [ПОДСИСТЕМА: например tasks/wiki/assistant].

Собери:
1. Состав (сервисы, типы, контракты, UI-компоненты, события).
2. Связи с другими подсистемами (события, сервисы, DAL).
3. Статус: что реализовано, что заглушка/не подключено.
4. Риски: безопасность, дублирование, «мёртвый код», разрыв контрактов.
5. Рекомендации: 3–7 конкретных шагов с приоритетами.

Формат ответа — краткий отчёт со ссылками `файл:строка`.
```

## Заметки

- Полный формат отчёта — по образцам в `docs/audits/`.
- Замени `[ПОДСИСТЕМА]` на нужную подсистему.
