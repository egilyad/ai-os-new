# Промпт: Управление админкой

## Назначение

Шаблон для диагностики и управления системой: здоровье, метрики,
провайдеры, задачи, настройки, сессии.

## Промпт

```
Проверь состояние системы (read-only, без изменений):

1. Здоровье: здоров ли сервер/ядро (observer.status).
2. Метрики: общие показатели (запросы, токены, ошибки).
3. Провайдеры: какие подключены, какие рекомендуются.
4. Задачи: есть ли зависшие/сломанные AGEMS-задачи.
5. Проверки: прогони /check и покажи результат.

Дай краткую сводку: что в норме, что требует внимания.
```

## Заметки

- Write/exec-действия идут через approvals (tool:exec).
- Для управления задачами используй вкладку «Команды» → AGEMS.
