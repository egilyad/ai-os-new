# Промпт: Разработка задачи

## Назначение

Шаблон для постановки задачи разработки: цель, объём, ограничения,
критерии готовности и порядок проверки.

## Промпт

```
Реализуй задачу: [ОПИСАНИЕ ЗАДАЧИ].

Требования:
1. Сначала изучи код: найди, где живёт смежная логика (grep/glob).
2. Минимум изменений: не трогай несвязанный код.
3. Следуй конвенциям проекта (стиль, типы, события, фазы).
4. Добавь/обнови тесты, если это меняет поведение.
5. Проверь ESLint + TypeScript по затронутым файлам.
6. Опиши, что изменилось и как проверить (файл:строка).

Не коммить без явного запроса.
```

## Заметки

- Для команд используй `/`-карточки в Sidekick (вкладка «Команды»).
- Регламент работы — в `AGENTS.md`.
