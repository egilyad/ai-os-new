# 04 — Модификаторы поведения

## Слой концепций

Модификаторы поведения — это параметры, которые изменяют **как агенты аргументируют**, а не то, о чём они спорят. Это «физика» системы дебатов — они влияют на стиль рассуждения, эмоциональный тон и логические ограничения, не меняя тему или базовые знания агента.

Существуют три системы модификаторов: **архетипы** (стиль мышления), **ограничения** (границы рассуждения) и **температура** (эмоциональный тон).

## Слой системного отображения

### Архетипы

```
DebateArchetypeId = 'scientist' | 'skeptic' | 'devils-advocate'
                   | 'pragmatist' | 'optimist' | 'cynic';
```

Определены в `debate-archetypes.ts`. Каждый соответствует блоку символов, внедряемому в системный промпт агента:

| Архетип         | Внедрение в промпт                                                       |
| --------------- | ------------------------------------------------------------------------ |
| Учёный          | "Вы мыслите как учёный. Требуйте доказательств. Используйте данные."     |
| Скептик         | "Вы глубоко скептичны. Ставьте под сомнение каждое предположение."       |
| Адвокат дьявола | "Спорьте против преобладающей точки зрения. Найдите слабое место."       |
| Прагматик       | "Фокусируйтесь на практических результатах. Что действительно работает?" |
| Оптимист        | "Найдите позитивный потенциал. Ищите возможности."                       |
| Циник           | "Предполагайте худшее. Указывайте на вероятные провалы."                 |

Применяется в UI через кнопки-переключатели. «Авто» не назначает архетип (использует системный промпт по умолчанию).

### Ограничения

```
DebateConstraint = 'none' | 'facts_only' | 'emotional_only' | 'data_driven'
                 | 'ethical_framework' | 'first_principles' | 'pragmatic';
```

Ограничения ограничивают **как** агент может рассуждать. Каждое соответствует записи `CONSTRAINT_PROMPTS`:

| Ограничение         | Правило                                                      | Используется в           |
| ------------------- | ------------------------------------------------------------ | ------------------------ |
| `none`              | Нет ограничений                                              | По умолчанию             |
| `facts_only`        | Только проверяемые факты, никаких спекуляций                 | Технические дебаты       |
| `emotional_only`    | Апелляция к эмоциям, ценностям, опыту                        | Человеко-центричные темы |
| `data_driven`       | Каждое утверждение должно ссылаться на данные или статистику | Исследовательский анализ |
| `ethical_framework` | Рассуждение через этические принципы                         | Политические дебаты      |
| `first_principles`  | Разложение до фундаментальных истин                          | Философские аргументы    |
| `pragmatic`         | Фокус на практических последствиях                           | Принятие решений         |

Назначается для каждого агента в UI при выборе стратегии `constrained`. В автоматическом режиме ограничения циклически перебираются между агентами.

### Температура (Тон)

```
debateTemperature: 0.0 – 1.0  (отображается на 5 уровней)
```

**Не** то же самое, что температура LLM — это управляет **инструкциями тона** в промпте:

| Диапазон | Уровень          | Внедрение в промпт                                                       |
| -------- | ---------------- | ------------------------------------------------------------------------ |
| 0.0–0.1  | Чистая логика    | "Используйте чистую логику. Никаких эмоций, никакой риторики."           |
| 0.2–0.3  | Аналитический    | "Будьте аналитичны и сдержанны. Предпочитайте данные эмоциям."           |
| 0.4–0.6  | Сбалансированный | "Балансируйте логические рассуждения с соответствующим акцентированием." |
| 0.7–0.8  | Страстный        | "Аргументируйте с убеждённостью и энергией."                             |
| 0.9–1.0  | Чистая эмоция    | "Используйте эмоциональные обращения. Страсть выше холодной логики."     |

Функция отображения: `buildTemperaturePrompt(temperature)` в `debate-runtime/debate-sync-manager.ts`.

## Слой поведения

- Архетипы, ограничения и температура внедряются в **системный промпт** — они изменяют поведение LLM через инструкцию, а не через параметры семплинга
- Они накладываются: агент может быть архетипом `Учёный` + ограничение `facts_only` + температура `0.7`
- Ограничения постфактум проверяются `scoreConstraintCompliance()` — эвристические проверки, которые штрафуют за нарушения (напр., спекуляции для `facts_only`, отсутствие данных для `data_driven`)
- Оценка соблюдения ограничений использует regex/сопоставление с шаблоном, а не LLM — быстро, но приблизительно
- Тон температуры отличается от температуры модели (`DebateConfig.temperature`), которая управляет случайностью семплинга LLM
- В сократической стратегии вопрошающий (Сократ) игнорирует архетип/ограничения — только респонденты их используют
