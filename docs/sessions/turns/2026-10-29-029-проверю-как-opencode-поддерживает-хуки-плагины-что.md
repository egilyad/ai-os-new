Проверю, как opencode поддерживает хуки/плагины, чтобы настроить автозапуск после каждого ответа. Тяну документацию.

Тяну документацию плагинов opencode (где есть жизненные циклы/события).

Документация ясна: у opencode есть плагины с хуками; событие `session.idle` срабатывает после завершения ответа. Делаю плагин, который после каждого ответа запускает экспорт.

Плагин создан: `.opencode/plugins/session-wiki.js` (валиден синтаксически). Он подписан на событие `session.idle` (срабатывает, когда ассистент завершил ответ) и запускает `scripts/export-opencode-turns.mjs` — так каждый ответ автоматом становится `.md` в `docs/sessions/turns/` + зеркало `docs/wiki/sessions/turns/`.

Два важных момента:
1. **`.opencode` в .gitignore** — плагин не попал в коммит и работает только локально на этой машине. Это нормально для личного хука, но если хочешь перенести его в репозиторий (чтобы был на всех машинах/в CI), можно либо раскомментить путь в `.gitignore`, либо положить в глобальную папку `~/.config/opencode/plugins/`.
2. **Нужен рестарт opencode** — плагины загружаются при старте, так что после перезапуска каждый новый ответ начнёт сохраняться автоматически, без команд.

Хочешь, чтобы я (а) добавил плагин в git (снять из ignore) или (б) оставил локально, а заодно проверил, что событие `session.idle` реально ловится после рестарта?
