# Ответ 144 · 2026-10-29

> Сессия: ses_e77960396ffeIfcCtCDoHVhKns · Раздел: **Сессии (opencode)** · Статус: verified

Запушено `c5bb8c7`. Причина «точек без связей» была найдена:

**Проблема:** кнопка «Синхронизация с вики» (`syncFromBuiltinWiki`) писала в стор только страницы, а рёбра графа (`store.links`) не создавала. `toFlowGraph()` строит рёбра из `links`, поэтому граф показывал узлы без связей.

**Фикс:** при синхронизации теперь дополнительно разбираются `[[wikilinks]]` из тел статей и создаются записи связей (`kind: wikilink`) с детерминированными id (`lnk:slugA->slugB`) — повторная синхронизация не плодит дубли. Ссылки создаются только между существующими slug.

После обновления: перезапусти `npm run dev`, зайди в `/wiki-brain` и нажми «Синхронизация с вики» — граф покажет связи. Если старые страницы уже были синхронизированы, повторное нажатие теперь добавит рёбра (страницы пропускаются, а связи достраиваются).
