- `docs/sessions/turns/` — источник (155 файлов, один на ответ).

- Индексы: `docs/sessions/turns/README.md` + `docs/wiki/sessions/turns/README.md`.

**Как работает:** скрипт `npm run session:turns` читает SQLite-базу opencode (`~/.local/share/opencode/opencode.db`), берёт последнюю сессию, вытаскивает текстовые ответы ассистента (`message` role=assistant + `part` type=text) и пишет по файлу на ответ (`YYYY-MM-DD-<seq>-<тема>.md`). Генератор вики зеркалит `docs/sessions` → `docs/wiki/sessions` рекурсивно, так что ничего не теряется при регенерации.

**Использование:**
```bash
npm run session:turns                          # последняя сессия
npm run session:turns -- --session <id>        # конкретная
npm run session:turns -- --dir ai-os           # по каталогу
```

**Честная оговорка:** это **не автоматически при каждом ответе в реальном времени** — это команда, которую нужно запустить (например, в конце сессии).
