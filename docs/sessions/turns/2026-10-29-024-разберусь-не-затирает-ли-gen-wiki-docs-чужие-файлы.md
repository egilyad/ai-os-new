Готово — запушено `2fd048c`. Теперь схема надёжного сохранения сессий:

**Как устроено**
- **Источник истины:** `docs/sessions/*.md` — коммитится в git, генераторами не трогается.
- **Скрипт:** `npm run session:export -- --title "..." --body file.md` пишет сессию в `docs/sessions/<дата>-<тема>.md` и пересобирает `docs/sessions/README.md`.
- **Генерация вики:** `scripts/gen-wiki-docs.mjs` (который стирает и пересоздаёт `docs/wiki`) теперь после сборки **зеркалит `docs/sessions` → `docs/wiki/sessions/`**. То есть сессии всегда видны в вики, даже после полной регенерации.

**Почему надёжно**
- `docs/sessions/` вне области `rmSync` генератора → ничего не затирается.
- Всё коммитится → история сессий в git.
- CI (`git diff --exit-code` после `gen:*`) теперь же требует, чтобы новые сессии были закоммичены — иначе зеркало разойдётся. Это правильное поведение.

**Как сохранить текущую/новую сессию:**
```bash
npm run session:export -- --title "Roadmap P0-P3" --date 2026-10-29 --body transcript.md
git add docs/sessions && git commit -m "docs(sessions): ..." && git push
```
