# 06 — Механизм интерпретации

## Концептуальный уровень

**DebateInterpreter** — это пост-аналитический слой системы, который преобразует сырые данные дебатов в читаемые выводы без вызовов LLM. Он намеренно реализован как **чистое вычисление**: никаких галлюцинаций интерпретации, никаких «агент, кажется, считает» — только структурные паттерны, извлечённые из графа аргументов и данных об участии.

## Системный уровень

**Расположение**: `src/kernel/services/debate-interpreter.ts`

**Класс**: `DebateInterpreter` — без зависимостей, инстанциируется как `private interpreter` внутри `DebateService`

**Точка входа**: `interpret(session: DebateSession): DebateInterpretation`

### Тип выходных данных

```
DebateInterpretation {
  summary: string;                                // Однострочная количественная сводка
  disagreementPeak: DisagreementPoint | null;      // Раунд максимальной интенсивности (null если <0.3)
  disagreementTimeline: Array<{round, intensity}>;  // Интенсивность по раундам
  trajectoryChangers: TrajectoryChanger[];          // Ключевые точки поворота
  constraintCorrelation?: ConstraintCorrelation;    // Статистика по ограничениям (только constrained)
  insights: string[];                              // Эвристические выводы
}
```

### Подвычисления

| Вычисление | Метод | Логика |
|------------|--------|-------|
| Сводка | `generateSummary()` | "N агентов обсуждали X за R раундов (M аргументов). За: N, Против: M. Сходимость: X%." |
| Шкала разногласий | `buildDisagreementTimeline()` | По раундам: `intensity = 1 − 2 * |0.5 − pros/total|` |
| Пик разногласий | `findDisagreementPeak()` | Раунд максимальной интенсивности, null если порог <0.3 |
| Точки поворота | `findTrajectoryChangers()` | 3 стратегии: сдвиги интенсивности ≥0.4, топ-3 наиболее связанных аргумента (режим дерева), аргументы стороны меньшинства |
| Корреляция ограничений | `analyzeConstraintCorrelation()` | По каждому ограничению: средняя глубина, уверенность, уровень оспаривания, соблюдение (штраф за спекуляцию) |
| Выводы | `generateInsights()` | Эвристики: уровень сходимости, баланс участия, баланс за/против, заметки по структуре графа |

## Поведенческий уровень

- Вызывается один раз при остановке дебатов: `this.interpretation = this.interpreter.interpret(session)`
- Все метрики (графа, активности, качества) вычисляются **перед** интерпретацией — интерпретация читает их
- Пики разногласий подсвечиваются в интерфейсе красным свечением с иконкой Zap
- Точки поворота дедуплицируются по argumentId (один аргумент может иметь несколько воздействий)
- Корреляция ограничений вычисляется только для стратегии `constrained`
- Если все раунды имеют интенсивность <0.3, `disagreementPeak` равен null (значимых разногласий не обнаружено)
- Выводы — это эвристические строки, такие как "Высокая сходимость предполагает близость к консенсусу" или "Хорошо сбалансированное участие"
