# 05 — Система метрик

## Концептуальный уровень

Система метрик преобразует артефакты дебатов (аргументы, утверждения, активность участников) в количественные оценки. Все метрики вычисляются **эвристически** — без вызовов LLM, что делает их быстрыми, детерминированными и воспроизводимыми. Существует три семейства метрик: **метрики графа** (структура), **метрики активности** (участие) и **метрики качества** (глубина, оригинальность, полезность).

## Системный уровень

### Метрики графа — `DebateGraphMetrics`

Вычисляются `computeGraphMetrics()` в DebateEngine. Имеют смысл только для стратегии `argument_tree`.

| Поле                | Вычисление                                           | Что измеряет                   |
| ------------------- | ---------------------------------------------------- | ------------------------------ |
| `totalNodes`        | Количество аргументов                                | Размер дебатов                 |
| `maxDepth`          | Самая длинная цепочка родитель→потомок               | Глубина рассуждений            |
| `avgDepth`          | Средняя глубина по всем узлам                        | Средняя длина цепочки          |
| `orphanRate`        | Узлы без валидного родителя / всего                  | Фрагментация дерева            |
| `branchingFactor`   | Среднее количество потомков на родителя              | Разнообразие аргументов        |
| `challengeDensity`  | Ссылки на родителя с противоположной позиции / всего | Вовлечённость в контраргументы |
| `refinementDensity` | Ссылки на родителя с той же позиции / всего          | Развитие vs. оспаривание       |

### Метрики активности — `ActivityMetrics`

Вычисляются `computeActivityMetrics()` в DebateEngine. Не зависят от стратегии.

| Компонент          | Поля                                                                          | Что измеряет                                  |
| ------------------ | ----------------------------------------------------------------------------- | --------------------------------------------- |
| `perAgent[]`       | `argumentCount`, `wordCount`, `avgConfidence`, `avgDepth`, `childrenReceived` | Вклад каждого агента                          |
| `mostDiscussed[]`  | Топ-5 аргументов по `childCount`                                              | Какие аргументы получили больше всего ответов |
| `roundIntensity[]` | Аргументов за раунд по индексу                                                | Темп дебатов                                  |

### Метрики качества — `QualityMetrics`

Вычисляются `computeQualityMetrics()` в DebateEngine. Три композита:

**DepthMetric (Глубина)** — композит из:

- `uniqueArguments` — аргументы с уникальной биграммной сигнатурой
- `lexicalDiversity` — уникальные слова / всего слов
- `uniqueBigrams` — уникальные символьные биграммы
- `topicBreadth` — редкие термины (частота ≤3) / уникальные слова
- `depthScore` = 0.25 * uniqueRatio + 0.25 * lexical + 0.25 * topicBreadth + 0.25 * bigrams/50

**OriginalityMetric (Оригинальность)** — композит из:

- `selfRepetition` — среднее сходство Жаккара между последовательными аргументами одного агента
- `crossRepetition` — среднее сходство Жаккара между разными агентами (последние 3 у каждого)
- `noveltyScore` = 1 − (0.4 * selfRep + 0.6 * crossRep)

**UsefulnessMetric (Полезность)** — композит из:

- `relevanceScore` — перекрытие тематических слов в аргументах
- `evidenceScore` — доля аргументов с числами/цитатами/паттернами свидетельств
- `structureScore` = 0.4 * hasParentLinks + 0.3 * balance + 0.3
- `usefulnessScore` = 0.4 * relevance + 0.3 * evidence + 0.3 * structure

## Поведенческий уровень

- Метрики графа имеют автоматические метки: например, `branchingFactor > 2` → "Высокое ветвление", `orphanRate > 0.3` → "Высокий уровень сирот"
- Метрики активности выделяют топ-3 самых активных агентов визуальным разделителем
- Метрики качества имеют цветовые пороги: depth > 0.6 = хорошо, originality > 0.5 = хорошо, usefulness > 0.5 = хорошо
- Все метрики вычисляются при остановке дебатов (в `stopDebate()`) и сохраняются в объекте сессии
- Метрики отображаются на боковой панели аналитики DebatePanel и являются реактивными (читаются из `session.graphMetrics` / `session.activityMetrics` / `session.qualityMetrics`)
- Показатель сходимости вычисляется отдельно во время дебатов (не при остановке) через сглаженное перекрытие Жаккара утверждений
