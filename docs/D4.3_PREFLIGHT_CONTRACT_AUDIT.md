## 7) Divergence — dual-write single-write mutation

**Dual-write flaw** `facade:32`:
```ts
const session = await old.createSession(input) // Council id = genId('council') council-abc
snapshot = councilToDebateSnapshot(session) // snapshot.id = same council-abc
debateEngine.createSession(snapshot.topology, snapshot.topic, ...) // BUT debate-engine:261 id = genId('debate') → debate-xyz IGNORES snapshot.id
```
Return discarded, no `mapping:council-abc→debate-xyz` persisted.

After any mutation on old only:

- **Phase:** Council `debate` vs Debate `created` (never transitioned) → `getSession` fallback `facade:49` always `return old.getSession(id)` prefers old, UI sees `debate` while Debate says `created` → zombie `failed` on reload `debate-engine:204`.
- **Messages/Facts:** New forum/whisper/fact appear in `councilMessages/Votes` but `DebateSnapshot.arguments` frozen at creation `[]`.
- **Judge/Votes:** Tally invisible to `blindEval/bayesianJudge` → `DEBATE_AGENT_SCORED` never emitted.
- **Winner:** `conclude` sets `winnerId/summary` in council only; `DebateStore` never `consensus/summarizing/completed` nor `DebateVerdictRecord`.
- **Version:** Debate `version:1` never `incrementVersion`, council no version — `saveSnapshot CAS 157` will conflict on future migration.

**Divergence risks:** split-brain reads, lost verdict generation `pipeline-builder:406`, provenance fork, `destroy` leak `DebateSessionContext 744`.
