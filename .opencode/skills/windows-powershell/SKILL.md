# Правила PowerShell 5.1

- Это Windows 10, PowerShell 5.1. Синтаксис PowerShell 7 НЕ использовать.
- Для длинных команд использовать здесь-строки и отдельные `.ps1`-скрипты.
- Перед destructive-операциями выводить `WhatIf` или dry-run.
- Проверять свободное место и память перед запуском тяжёлых процессов (машина слабая: AMD E-350, 11.6 ГБ ОЗУ).
- Не предполагать наличие Bun; использовать Node.js и npm (`node ./node_modules/...` напрямую).
- `npx` и `.ps1` могут быть заблокированы политикой — обходить вызовом node.
- Пути с пробелами всегда в двойных кавычках.
- Для цепочек команд использовать `cmd1; if ($?) { cmd2 }` (без `&&`).
- Не оставлять долгоидущих процессов (daemon) без необходимости.

## Purpose

Use for: любых команд на этой Windows-машине — не сломать синтаксис PowerShell 5.1, не потерять данные и не перегрузить слабый ПК.

## Examples

- `проверь свободное место перед копированием`
- `run tests using node ./node_modules/vitest/vitest.mjs`
- Ожидаемый вывод: `Get-PSDrive C | Select-Object Free`, затем команда с `if ($?)`.

## Error handling

Перед destructive-операцией делай dry-run/`WhatIf`. Если `$?` ложное — останови цепочку и сообщи причину; не продолжай по расписанию.

## Limitations

Правила специфичны для PowerShell 5.1 и Windows 10; в PowerShell 7 и Linux часть команд отличается.

## Troubleshooting

`&&` не работает — замени на `; if ($?) { ... }`. Скрипт заблокирован политикой — вызови `.exe` через call-оператор с полным путём.
